📝 HW6: Numerical Differentiation

Exercise 1(a) หน้า 9 + Exercise 4 หน้า 10 — Two-point backward difference และ Taylor error analysis

🔗 หัวข้อที่เกี่ยวข้อง

อ่านทบทวน บทที่ 9 — Numerical Differentiation โดยเฉพาะส่วน Finite-Difference formulas (forward/backward/central) และ Taylor-series error analysis

Part 1 — Exercise 1(a): Two-Point Backward Difference

โจทย์

The following data is given for the stopping distance of a car versus the speed at which it begins braking:

Speed (km/h)3248648096
Stopping distance (m)610243447

Calculate the rate of change of the stopping distance at a speed of 80 km/h using the two-point backward difference formula.

✅ Guided Solution — Part 1

Step 1: เขียนสูตร Two-Point Backward Difference

สูตร backward difference อันดับที่หนึ่ง (first-order) ใช้จุด \(x_i\) กับจุด ก่อนหน้า \(x_{i-1}\):

\[ f'(x_i) \;\approx\; \frac{f(x_i) - f(x_{i-1})}{h} \]

โดย \(h = x_i - x_{i-1}\) คือระยะห่างระหว่างจุด

💡 ชื่อ "backward" มาจาก การใช้ข้อมูล ย้อนหลัง (จุดก่อน \(x_i\)) ประโยชน์: ใช้ได้แม้ไม่รู้ค่าถัดไป (เช่น ตอน real-time measurement ที่ยังไม่มีข้อมูลอนาคต)

Step 2: ระบุจุดและค่า \(h\)

เราต้องการ \(f'(80)\) ดังนั้น:

  • \(x_i = 80\), \(f(x_i) = 34\) m
  • \(x_{i-1} = 64\) (จุดก่อนหน้าในตาราง), \(f(x_{i-1}) = 24\) m
  • \(h = 80 - 64 = 16\) km/h

Step 3: แทนค่าในสูตร

\[ f'(80) \;\approx\; \frac{f(80) - f(64)}{16} \;=\; \frac{34 - 24}{16} \;=\; \frac{10}{16} \]

\(\boxed{\, f'(80) \approx 0.625 \;\text{m per km/h} \,}\)

Step 4: ตีความทางฟิสิกส์

ที่ความเร็ว 80 km/h: ถ้ารถวิ่งเร็วขึ้น 1 km/h ระยะเบรก (stopping distance) จะเพิ่มขึ้นประมาณ 0.625 เมตร

หรือพูดอีกแบบ: เร็วขึ้น 10 km/h → ต้องการระยะเบรกเพิ่มราว 6.25 เมตร

Step 5: เปรียบเทียบกับ Forward / Central Difference (เสริม)

ลองคำนวณด้วยสูตรอื่นที่จุดเดียวกัน (\(x = 80\)) เพื่อเห็นความแตกต่าง:

วิธี สูตร คำนวณ ค่า (m per km/h) Error order
Backward (คำตอบที่โจทย์ถาม) \(\dfrac{f(x_i) - f(x_{i-1})}{h}\) \(\dfrac{34 - 24}{16}\) \(\mathbf{0.6250}\) \(O(h)\)
Forward \(\dfrac{f(x_{i+1}) - f(x_i)}{h}\) \(\dfrac{47 - 34}{16}\) \(0.8125\) \(O(h)\)
Central (แม่นที่สุด) \(\dfrac{f(x_{i+1}) - f(x_{i-1})}{2h}\) \(\dfrac{47 - 24}{32}\) \(0.7188\) \(O(h^2)\)

📊 ข้อสังเกต: ค่า backward (0.625) และ forward (0.8125) ต่างกันพอสมควร เพราะข้อมูลไม่เรียบ (non-linear). Central difference (0.719) อยู่กึ่งกลาง ซึ่งโดยทั่วไปแม่นที่สุดเพราะ error เป็น \(O(h^2)\) แต่โจทย์ถามแค่ backward เท่านั้น

📊 สรุปคำตอบ Part 1

  • สูตรที่ใช้: Two-point backward difference
  • ค่า \(h\): 16 km/h
  • คำนวณ: \((34 - 24)/16\)
  • คำตอบ: \(f'(80) \approx \mathbf{0.625}\) m per km/h

Part 2 — Exercise 4: Taylor-Series Error Term

โจทย์

Using Taylor series, establish the error term for the formula

\[ f'(0) \;\approx\; \frac{1}{2h}\bigl[\, f(2h) - f(0) \,\bigr]. \]

เป้าหมาย: หาว่าสูตรนี้มี error เท่าไร และเป็น order ที่เท่าใดของ \(h\)

✅ Guided Solution — Part 2

Step 1: ไอเดีย — ใช้ Taylor expansion รอบจุด \(x = 0\)

วิธี: เขียน \(f(2h)\) ด้วย Taylor series รอบ \(x = 0\) → เอามาเทียบกับสูตรที่โจทย์ให้ → ส่วนที่เหลือคือ error

💡 ทริกสำคัญ: Taylor expansion ของ \(f(x+a)\) รอบ \(x\) คือ \[ f(x+a) = f(x) + a\,f'(x) + \tfrac{a^2}{2!}f''(x) + \tfrac{a^3}{3!}f'''(x) + \ldots \] ในที่นี้ \(x = 0, a = 2h\)

Step 2: กางสูตร \(f(2h)\) ด้วย Taylor

\[ f(2h) \;=\; f(0) + (2h)\,f'(0) + \frac{(2h)^2}{2!}\,f''(0) + \frac{(2h)^3}{3!}\,f'''(0) + \frac{(2h)^4}{4!}\,f^{(4)}(0) + \cdots \]

ลดรูป แต่ละพจน์:

  • \(\dfrac{(2h)^2}{2!} = \dfrac{4h^2}{2} = 2h^2\)
  • \(\dfrac{(2h)^3}{3!} = \dfrac{8h^3}{6} = \dfrac{4h^3}{3}\)
  • \(\dfrac{(2h)^4}{4!} = \dfrac{16h^4}{24} = \dfrac{2h^4}{3}\)
\[ f(2h) \;=\; f(0) + 2h\,f'(0) + 2h^2\,f''(0) + \tfrac{4h^3}{3}\,f'''(0) + \tfrac{2h^4}{3}\,f^{(4)}(0) + \cdots \]

Step 3: ย้ายข้างเพื่อจัดรูปสูตรที่โจทย์ให้

ลบ \(f(0)\) ออกจากสองข้าง:

\[ f(2h) - f(0) \;=\; 2h\,f'(0) + 2h^2\,f''(0) + \tfrac{4h^3}{3}\,f'''(0) + \cdots \]

หารด้วย \(2h\) ทั้งสองข้าง:

\[ \frac{f(2h) - f(0)}{2h} \;=\; f'(0) \;+\; h\,f''(0) \;+\; \tfrac{2h^2}{3}\,f'''(0) \;+\; \tfrac{h^3}{3}\,f^{(4)}(0) + \cdots \]

Step 4: แยก \(f'(0)\) ออกมา

ย้ายทุกเทอมที่ไม่ใช่ \(f'(0)\) ไปอีกข้าง:

\[ f'(0) \;=\; \frac{f(2h) - f(0)}{2h} \;\underbrace{- \;h\,f''(0) - \tfrac{2h^2}{3}\,f'''(0) - \cdots}_{\text{Error term}} \]

Leading error term: \(\boxed{\, -\,h\,f''(0) \,}\) → เป็น \(O(h)\)

Step 5: Error ที่ "แม่น" (Lagrange remainder)

Taylor's theorem รับประกันว่าถ้าตัด series ที่เทอมอันดับ 2 เราจะเขียน:

\[ f(2h) \;=\; f(0) + 2h\,f'(0) + \frac{(2h)^2}{2!}\,f''(\xi) \]

โดย \(\xi\) คือจุดใด ๆ ใน \((0, 2h)\) (Mean Value Theorem สำหรับ Taylor)

จัดรูป:

\[ \frac{f(2h) - f(0)}{2h} \;=\; f'(0) \;+\; h\,f''(\xi) \]

ย้ายข้าง:

\[ f'(0) \;=\; \frac{f(2h) - f(0)}{2h} \;-\; h\,f''(\xi), \qquad \xi \in (0, 2h) \]

🎯 Error term ที่แน่นอน: \[ E(h) \;=\; -\,h\,f''(\xi), \quad \xi \in (0, 2h) \] หรือเขียนด้วย big-O: \(\;E(h) = O(h)\)

Step 6: เปรียบเทียบกับสูตร differentiation อื่น

สูตรที่โจทย์ให้ \(f'(0) \approx \dfrac{f(2h) - f(0)}{2h}\) หน้าตาคล้าย central difference แต่จริง ๆ แล้วมันคือ forward difference ที่ใช้ step 2h จึงมี error แค่ \(O(h)\) ไม่ใช่ \(O(h^2)\)

สูตร Expression Leading error Order
สูตรโจทย์ (forward, step 2h) \(\dfrac{f(2h) - f(0)}{2h}\) \(-\,h\,f''(\xi)\) \(O(h)\)
Forward มาตรฐาน (step h) \(\dfrac{f(h) - f(0)}{h}\) \(-\tfrac{h}{2}\,f''(\xi)\) \(O(h)\)
Central (step h, สมมาตร) \(\dfrac{f(h) - f(-h)}{2h}\) \(-\tfrac{h^2}{6}\,f'''(\xi)\) \(\mathbf{O(h^2)}\) ✨

💭 บทเรียน: หน้าตาสูตร "คล้าย central" (มี \(2h\) ที่ตัวหาร) ไม่ได้แปลว่าแม่น central ต้องมีจุด สมมาตร รอบจุดที่หา (คือ \(f(h)\) และ \(f(-h)\)) จึงจะได้ accuracy \(O(h^2)\). สูตรโจทย์ใช้ \(f(0)\) และ \(f(2h)\) ซึ่งไม่สมมาตร → ยังแค่ \(O(h)\)

📊 สรุปคำตอบ Part 2

  • Taylor expansion: \(f(2h) = f(0) + 2h f'(0) + 2h^2 f''(0) + \tfrac{4h^3}{3}f'''(0) + \cdots\)
  • Error term (series form): \(-\,h\,f''(0) - \tfrac{2h^2}{3}f'''(0) - \cdots\)
  • Error term (Lagrange form): \(E(h) = -\,h\,f''(\xi), \; \xi \in (0, 2h)\)
  • Order of accuracy: \(\boxed{\,O(h)\,}\) — first-order accurate

💻 Python Code (สำหรับตรวจคำตอบ Part 1 + ทดสอบ error order Part 2)

import numpy as np

# ========== Part 1: Backward Difference ==========
speed    = np.array([32, 48, 64, 80, 96])
distance = np.array([ 6, 10, 24, 34, 47])

i = 3   # index of x = 80
h = speed[i] - speed[i-1]              # = 16
backward = (distance[i] - distance[i-1]) / h
forward  = (distance[i+1] - distance[i]) / h
central  = (distance[i+1] - distance[i-1]) / (2*h)

print(f"Backward f'(80) = {backward:.4f} m per km/h")   # 0.6250
print(f"Forward  f'(80) = {forward:.4f} m per km/h")    # 0.8125
print(f"Central  f'(80) = {central:.4f} m per km/h")    # 0.7188

# ========== Part 2: Verify error order O(h) ==========
# Test with f(x) = sin(x), so f'(0) = cos(0) = 1
# Formula: f'(0) ≈ (f(2h) - f(0)) / (2h)
print("\nError test for f(x)=sin(x), true f'(0) = 1:")
print(f"{'h':>10} {'approx':>12} {'error':>12} {'error/h':>12}")
for h in [0.1, 0.05, 0.025, 0.0125, 0.00625]:
    approx = (np.sin(2*h) - np.sin(0)) / (2*h)
    err = approx - 1.0
    print(f"{h:10.5f} {approx:12.8f} {err:12.5e} {err/h:12.5e}")
# สังเกต: error/h คงที่ประมาณ -1 → ยืนยัน error ≈ -h·f''(0) = -h·(-sin(0)+...)
# สำหรับ sin: f''(0)=0, O(h^2) จะมา dominant แต่สำหรับฟังก์ชันทั่วไป error ∝ h
