📝 HW5: Least-Squares Regression (Monod Growth)

Exercise 6, page 21 — Fit Monod equation โดยการ linearize และคำนวณ R²

🔗 หัวข้อที่เกี่ยวข้อง

อ่านทบทวน บทที่ 6 — Least-Squares Regression โดยเฉพาะ Section 6 (Nonlinear Linearization) และ Section 4 (R²)

Problem (Exercise 6)

โจทย์ (English):

An investigator has reported the data tabulated below for an experiment to determine the growth rate of bacteria \(k\) (per a time unit), as a function of oxygen concentration \(c\) (mg/L). It is known that such data can be modeled by the following equation:

\[ k = \frac{k_{max} \, c^2}{c_s + c^2} \]

where \(c_s\) and \(k_{max}\) are parameters.

Tasks:

  1. Use a transformation to linearize this equation
  2. Use linear regression to estimate \(c_s\) and \(k_{max}\)
  3. Compute the corresponding \(R^2\)
  4. Predict the growth rate at \(c = 2\) mg/L

Data:

\(c\) (mg/L)0.50.81.52.54
\(k\)1.12.45.37.68.9

✅ Guided Solution

Step 1: Linearize สมการ Monod

เริ่มจาก \( k = \dfrac{k_{max} \, c^2}{c_s + c^2} \) — กลับทั้งสองข้าง:

\[ \frac{1}{k} = \frac{c_s + c^2}{k_{max} \, c^2} = \frac{c_s}{k_{max}} \cdot \frac{1}{c^2} + \frac{1}{k_{max}} \]

ตั้งตัวแปรใหม่:

\[ Y = \frac{1}{k}, \quad X = \frac{1}{c^2} \]

ได้สมการเชิงเส้น:

\[ Y = a_0 + a_1 X \quad \text{โดย} \quad a_0 = \frac{1}{k_{max}}, \; a_1 = \frac{c_s}{k_{max}} \]

💡 หลังหา \(a_0, a_1\) แล้ว:

\(k_{max} = \dfrac{1}{a_0}, \quad c_s = \dfrac{a_1}{a_0} = a_1 \cdot k_{max}\)

Step 4: หา \(a_1, a_0\) จากสูตรสำเร็จ

\[ a_1 = \frac{n S_{XY} - S_X S_Y}{n S_{XX} - (S_X)^2} \]

แทนค่า:

\(a_1 = \dfrac{5 \times 4.3994 - 6.2294 \times 1.7585}{5 \times 18.6684 - (6.2294)^2}\)

\(= \dfrac{21.9970 - 10.9541}{93.3420 - 38.8054} = \dfrac{11.0429}{54.5366}\)

\(\boxed{a_1 \approx 0.2025}\)

Shortcut สำหรับ \(a_0\): \(a_0 = \bar{Y} - a_1 \bar{X}\)

\(\bar{X} = 6.2294/5 = 1.2459, \quad \bar{Y} = 1.7585/5 = 0.3517\)

\(a_0 = 0.3517 - 0.2025 \times 1.2459 = 0.3517 - 0.2523 = 0.0994\)

\(\boxed{a_0 \approx 0.0994}\)

Step 5: แปลงกลับเป็น \(k_{max}, c_s\)

\(k_{max} = \dfrac{1}{a_0} = \dfrac{1}{0.0994}\)

\(\boxed{k_{max} \approx 10.06}\)

\(c_s = a_1 \cdot k_{max} = 0.2025 \times 10.06\)

\(\boxed{c_s \approx 2.04}\)

Model สุดท้าย:

\[ k = \frac{10.06 \, c^2}{2.04 + c^2} \]

Step 7: ประมาณ growth rate ที่ \(c = 2\) mg/L

แทน \(c = 2\) ใน model:

\[ k(2) = \frac{10.06 \times 4}{2.04 + 4} = \frac{40.24}{6.04} \]

\(\boxed{k(2) \approx 6.66 \text{ (per time unit)}}\)

📊 สรุปคำตอบทั้งหมด

  • Linearization: \(Y = 1/k, X = 1/c^2\) → \(Y = a_0 + a_1 X\)
  • \(a_0 \approx 0.0994, \; a_1 \approx 0.2025\)
  • \(k_{max} \approx 10.06\)
  • \(c_s \approx 2.04\)
  • \(R^2 \approx 1.0000\) (perfect fit)
  • \(k(c=2) \approx 6.66\)

💻 Python Code (สำหรับตรวจคำตอบ)

import numpy as np

c = np.array([0.5, 0.8, 1.5, 2.5, 4.0])
k = np.array([1.1, 2.4, 5.3, 7.6, 8.9])

# Linearize: Y = 1/k, X = 1/c^2
X = 1 / c**2
Y = 1 / k

# Linear regression
n = len(c)
Sx, Sy = X.sum(), Y.sum()
Sxx = (X**2).sum()
Sxy = (X*Y).sum()

a1 = (n*Sxy - Sx*Sy) / (n*Sxx - Sx**2)
a0 = Y.mean() - a1*X.mean()

k_max = 1/a0
c_s = a1 * k_max
print(f"a0={a0:.4f}, a1={a1:.4f}")
print(f"k_max={k_max:.4f}, c_s={c_s:.4f}")

# R^2
k_pred = k_max*c**2 / (c_s + c**2)
SS_res = ((k - k_pred)**2).sum()
SS_tot = ((k - k.mean())**2).sum()
R2 = 1 - SS_res/SS_tot
print(f"R^2 = {R2:.6f}")

# Predict at c=2
k_at_2 = k_max*4 / (c_s + 4)
print(f"k(c=2) = {k_at_2:.4f}")
