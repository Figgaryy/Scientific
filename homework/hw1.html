📝 HW1: Taylor Polynomial Error

Assignment 1 — Maximum error ของ Taylor polynomial สำหรับ \(e^{-0.2}\)

🔗 หัวข้อที่เกี่ยวข้อง

อ่านทบทวน บทที่ 1 — Errors & Taylor Series โดยเฉพาะ Taylor's Remainder Theorem และตัวอย่าง 1.5

Problem 1

โจทย์: What is the maximum possible error if the Taylor polynomial of degree 4 for the function \(f(x) = e^x\) centered at 0 is used to approximate \(e^{-0.2}\)? Use Taylor's Remainder Theorem.

แปลเป็นภาษาไทย: Maximum error สูงสุดของ Taylor polynomial degree 4 ของ \(f(x) = e^x\) รอบ 0 เมื่อใช้ประมาณ \(e^{-0.2}\) คือเท่าใด? ใช้ Taylor's Remainder Theorem

✅ Guided Solution

Step 1: เขียน Taylor's Remainder Theorem

สำหรับ Taylor polynomial degree \(n\) ของ \(f\) รอบ \(c\):

\[ R_{n+1}(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - c)^{n+1}, \quad \xi \text{ อยู่ระหว่าง } c \text{ และ } x \]

Step 2: ระบุค่าที่ให้

  • \(f(x) = e^x\); \(f^{(k)}(x) = e^x\) สำหรับทุก \(k\)
  • \(c = 0\) (centered at 0)
  • \(n = 4\) (degree 4)
  • \(x = -0.2\)
  • \(\xi \in (-0.2, 0)\)

Step 3: แทนใน Remainder

\[ |R_5(-0.2)| = \left|\frac{e^\xi}{5!}(-0.2 - 0)^5\right| = \frac{|e^\xi|}{120}(0.2)^5 \]

Step 4: หา upper bound ของ \(|e^\xi|\)

สำหรับ \(\xi \in (-0.2, 0)\), \(e^\xi\) เป็นฟังก์ชันเพิ่ม → maximum อยู่ที่ \(\xi = 0\):

\[ |e^\xi| < e^0 = 1 \quad \text{สำหรับ } \xi \in (-0.2, 0) \]

Step 5: คำนวณค่าสูงสุด

\[ |R_5(-0.2)| \leq \frac{1}{120}(0.2)^5 = \frac{0.00032}{120} = 2.6667 \times 10^{-6} \]
✅ คำตอบสุดท้าย

Maximum possible error \(\approx 2.67 \times 10^{-6}\)

🔍 ตรวจสอบ

ค่าจริง: \(e^{-0.2} = 0.81873075\)

Taylor 4th order: \(p_4(-0.2) = 1 - 0.2 + \frac{(-0.2)^2}{2} + \frac{(-0.2)^3}{6} + \frac{(-0.2)^4}{24}\)

\(= 1 - 0.2 + 0.02 - 0.001333 + 0.0000667 = 0.8187333\)

Actual error: \(|0.81873075 - 0.8187333| = 2.6 \times 10^{-6}\) ✅ ตรงกับ upper bound
