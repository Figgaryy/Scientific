Problem 1: \(x^4 - 2x^3 = 10\)

โจทย์: Consider the equation \(x^4 - 2x^3 = 10\). ประมาณราก \(x^*\) โดยใช้:

  • (a) Bisection: \([a, b] = [1, 3]\)
  • (b) False Position: \([a, b] = [1, 3]\)
  • (c) Newton-Raphson: \(x_0 = 1\)
  • (d) Secant: \(x_0 = 1, x_1 = 3\)
  • (e) Fixed-Point: \(x_0 = 1\), เลือก \(g(x)\) เหมาะสม

Requirements:

  • เลือก stopping criteria เดียวใช้กับทุกวิธี
  • แสดง approximations และ errors จากทุก iteration
  • เปรียบเทียบ final approximation และจำนวน iteration
  • ส่ง code ทั้งหมด

✅ Guided Solution

ตั้งสมการ: \(f(x) = x^4 - 2x^3 - 10 = 0\)

\(f(1) = 1 - 2 - 10 = -11\), \(f(3) = 81 - 54 - 10 = 17\) → มีรากใน [1, 3]

Stopping criterion: \(|f(x)| \leq 10^{-5}\); \(N_{max} = 100\)

(b) False Position — 14 iterations

สูตร \(x_j = \frac{a f(b) - b f(a)}{f(b) - f(a)}\)

Iter 1: \(x_1 = 1.7857\); Iter 2: \(x_2 = 2.2685\); Iter 3: \(x_3 = 2.4789\); ... Iter 14: \(x_{14} = 2.5814\)

(c) Newton-Raphson — 9 iterations (converge to \(-1.4287\) — รากอื่น!)

\(f'(x) = 4x^3 - 6x^2\)

\(x_0 = 1\); \(f'(1) = -2\); \(x_1 = 1 - (-11)/(-2) = -4.5\) — กระโดดไปทางลบ!

Iter 9: \(x_9 = -1.4287\); \(|f(-1.4287)| = 3.55 \times 10^{-15}\)

⚠️ Newton ที่ \(x_0 = 1\) converge ไปที่รากลบ (\(-1.4287\)) เพราะ \(f'(1) = -2\) เล็ก + slope ชี้ไปทางลบ — ควรใช้ \(x_0 = 3\) เพื่อได้รากบวก

(d) Secant — 11 iterations

\(x_0 = 1, x_1 = 2\); \(f(1) = -11, f(2) = -10\)

\(m_1 = 1\); \(x_2 = 2 - (-10)/1 = 12\) — กระโดดไปไกล

Iter 11: \(x_{11} = 2.5814\)

(e) Fixed-Point — เลือก \(g(x)\)

จาก \(x^4 - 2x^3 = 10\), สามารถ rearrange ได้หลายแบบ เช่น:

  • \(g(x) = (2x^3 + 10)^{1/4}\) — น่าจะ converge (root เป็น bounded)
  • \(g(x) = x + f(x)/c\) สำหรับ \(c\) ใหญ่พอ

ตัวอย่าง \(g(x) = (2x^3 + 10)^{1/4}\):

Iter 1: \(x_1 = (2 + 10)^{1/4} = 12^{1/4} = 1.8612\)

Iter 2: \(x_2 = (2(1.8612)^3 + 10)^{1/4} = (12.895 + 10)^{1/4} = 2.1875\)

Iter n: converge ไปที่ 2.5814 (converge ค่อนข้างช้า, ประมาณ 30+ iterations)

Problem 2: IRR สำหรับ ThaiESG Fund 💰

โจทย์: การลงทุน 5 ปีใน Thailand ESG (ThaiESG) sustainability fund

  • Initial investment: 100,000 THB
  • Projected returns: ปี 1-5 = 15,000; 20,000; 25,000; 30,000; 35,000 THB

Find Internal Rate of Return (IRR):

\[ f(r) = -100{,}000 + \frac{15{,}000}{1+r} + \frac{20{,}000}{(1+r)^2} + \frac{25{,}000}{(1+r)^3} + \frac{30{,}000}{(1+r)^4} + \frac{35{,}000}{(1+r)^5} = 0 \]

Substitution: ให้ \(x = 1 + r\), หารด้วย 5,000:

\[ f(x) = -20 + \frac{3}{x} + \frac{4}{x^2} + \frac{5}{x^3} + \frac{6}{x^4} + \frac{7}{x^5} = 0 \]

สมมติราก \(x^* \in [1.0, 1.2]\); คำนวณ \(r = x^* - 1\) (as percentage)

ใช้ 5 methods:

  • (a) Bisection: \([1.0, 1.2]\)
  • (b) False Position: \([1.0, 1.2]\)
  • (c) Newton: \(x_0 = 1.2\)
  • (d) Secant: \(x_0 = 1.2, x_1 = 1.1\)
  • (e) Fixed-Point: \(x_0 = 1.2\), \(g(x) = \left(\frac{3}{20}x^4 + \frac{4}{20}x^3 + \frac{5}{20}x^2 + \frac{6}{20}x + \frac{7}{20}\right)^{1/5}\)

(b) False Position: \(x_1 = \frac{1 \cdot f(1.2) - 1.2 \cdot f(1)}{f(1.2) - f(1)}\)

\(= \frac{1 \cdot (-6.122) - 1.2 \cdot 5}{-6.122 - 5} = \frac{-6.122 - 6}{-11.122} = 1.090\)

(c) Newton: \(f'(x) = -\frac{3}{x^2} - \frac{8}{x^3} - \frac{15}{x^4} - \frac{24}{x^5} - \frac{35}{x^6}\)

ที่ \(x_0 = 1.2\): \(f(1.2) = -6.122\); \(f'(1.2) \approx -47.6\)

\(x_1 = 1.2 - (-6.122)/(-47.6) = 1.2 - 0.1287 = 1.0713\)

Iter 2, 3: converge เร็ว ไปที่ \(x^* \approx 1.0815\)

(d) Secant: \(x_0 = 1.2, x_1 = 1.1\)

\(m_1 = (f(1.1) - f(1.2))/(1.1 - 1.2) = (-0.968 - (-6.122))/(-0.1) = -51.54\)

\(x_2 = 1.1 - (-0.968)/(-51.54) = 1.1 - 0.0188 = 1.0812\)

(e) Fixed-Point

\(g(x) = \left(\frac{3x^4 + 4x^3 + 5x^2 + 6x + 7}{20}\right)^{1/5}\)

ที่ \(x_0 = 1.2\): \(x_1 = g(1.2) = \left(\frac{3(2.0736) + 4(1.728) + 5(1.44) + 6(1.2) + 7}{20}\right)^{1/5}\)

\(= \left(\frac{6.221 + 6.912 + 7.2 + 7.2 + 7}{20}\right)^{1/5} = (1.727)^{1/5} = 1.116\)

Iter n: converge ไปที่ \(x^* \approx 1.0815\)

✅ Final IRR

\(x^* \approx 1.0815\) → \(r = x^* - 1 = 0.0815 = \boxed{8.15\%}\) ต่อปี

แสดงว่ากองทุน ThaiESG นี้ให้ผลตอบแทน internal rate ประมาณ 8.15% ต่อปี — เป็นการลงทุนที่ดี
