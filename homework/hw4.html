📝 HW4: Nonlinear System

Exercise — Newton's method + Fixed-point iteration สำหรับระบบ 2 ตัวแปร

🔗 หัวข้อที่เกี่ยวข้อง

อ่านทบทวน บทที่ 5 — Nonlinear Systems

Exercise: ระบบ Nonlinear

ระบบสมการ:

\[ \begin{aligned} y - x^3 &= 0 \\ 4x^2 + 9y^2 &= 36 \end{aligned} \]

Initial value: \(\mathbf{x}^{(0)} = [1, 2]^T\); ทำ 2 iterations โดย:

  1. (i) Newton's method
  2. (ii) Fixed-point method ด้วย:
    • \(g_1(x, y) = (4x - x^3 - y)/4\)
    • \(g_2(x, y) = -x^2/9 + (4y - y^2)/4 + 1\)

✅ Part (i): Newton's Method

Setup

ตั้ง \(f_1(x, y) = y - x^3\); \(f_2(x, y) = 4x^2 + 9y^2 - 36\)

Jacobian:

\[ \mathbf{J}(x, y) = \begin{bmatrix} \frac{\partial f_1}{\partial x} & \frac{\partial f_1}{\partial y} \\ \frac{\partial f_2}{\partial x} & \frac{\partial f_2}{\partial y} \end{bmatrix} = \begin{bmatrix} -3x^2 & 1 \\ 8x & 18y \end{bmatrix} \]

Iteration 1: ที่ \((x_0, y_0) = (1, 2)\)

\(\mathbf{f}(1, 2) = \begin{bmatrix} 2 - 1 \\ 4 + 36 - 36 \end{bmatrix} = \begin{bmatrix} 1 \\ 4 \end{bmatrix}\)

\(\mathbf{J}(1, 2) = \begin{bmatrix} -3 & 1 \\ 8 & 36 \end{bmatrix}\); \(\det = -108 - 8 = -116\)

\(\mathbf{J}^{-1} = \frac{1}{-116}\begin{bmatrix} 36 & -1 \\ -8 & -3 \end{bmatrix} = \begin{bmatrix} -0.3103 & 0.00862 \\ 0.06897 & 0.02586 \end{bmatrix}\)

Newton: \(\mathbf{x}^{(1)} = \mathbf{x}^{(0)} - \mathbf{J}^{-1}\mathbf{f}\)

\(\mathbf{J}^{-1}\mathbf{f} = \begin{bmatrix} -0.3103(1) + 0.00862(4) \\ 0.06897(1) + 0.02586(4) \end{bmatrix} = \begin{bmatrix} -0.2758 \\ 0.1724 \end{bmatrix}\)

\(\mathbf{x}^{(1)} = \begin{bmatrix} 1 \\ 2 \end{bmatrix} - \begin{bmatrix} -0.2758 \\ 0.1724 \end{bmatrix} = \begin{bmatrix} 1.2758 \\ 1.8276 \end{bmatrix}\)

Iteration 2: ที่ \((1.2758, 1.8276)\)

\(f_1 = 1.8276 - (1.2758)^3 = 1.8276 - 2.0770 = -0.2494\)

\(f_2 = 4(1.2758)^2 + 9(1.8276)^2 - 36 = 6.5089 + 30.061 - 36 = 0.5699\)

\(\mathbf{J}(1.2758, 1.8276) = \begin{bmatrix} -3(1.6281) & 1 \\ 10.206 & 32.897 \end{bmatrix} = \begin{bmatrix} -4.884 & 1 \\ 10.206 & 32.897 \end{bmatrix}\)

\(\det = -160.7 - 10.206 = -170.9\)

\(\mathbf{J}^{-1} = \frac{1}{-170.9}\begin{bmatrix} 32.897 & -1 \\ -10.206 & -4.884 \end{bmatrix} = \begin{bmatrix} -0.1925 & 0.00585 \\ 0.0597 & 0.0286 \end{bmatrix}\)

\(\mathbf{J}^{-1}\mathbf{f} = \begin{bmatrix} -0.1925(-0.2494) + 0.00585(0.5699) \\ 0.0597(-0.2494) + 0.0286(0.5699) \end{bmatrix} = \begin{bmatrix} 0.0514 \\ 0.00141 \end{bmatrix}\)

\(\mathbf{x}^{(2)} = \begin{bmatrix} 1.2758 \\ 1.8276 \end{bmatrix} - \begin{bmatrix} 0.0514 \\ 0.00141 \end{bmatrix} = \begin{bmatrix} 1.2244 \\ 1.8262 \end{bmatrix}\)

Absolute Error (Iter 2, 2-norm):

\(\|\mathbf{x}^{(2)} - \mathbf{x}^{(1)}\|_2 = \sqrt{(1.2244-1.2758)^2 + (1.8262-1.8276)^2} = 0.0514\)

Absolute Error (∞-norm): \(\max(0.0514, 0.0014) = 0.0514\)

Solution converge ไปที่ \((x^*, y^*) \approx (1.224, 1.833)\) — ใกล้ Newton iter 2 มากแล้ว! (converge เร็ว)

✅ Part (ii): Fixed-Point Method

Setup

Iteration functions:

  • \(g_1(x, y) = (4x - x^3 - y)/4\)
  • \(g_2(x, y) = -x^2/9 + (4y - y^2)/4 + 1\)

ตรวจ Convergence (ที่ initial point (1, 2))

\(\frac{\partial g_1}{\partial x} = (4 - 3x^2)/4\); ที่ (1, 2): \((4-3)/4 = 0.25\)

\(\frac{\partial g_1}{\partial y} = -1/4 = -0.25\)

Sum row 1: \(0.25 + 0.25 = 0.5 \leq 1\) ✅

\(\frac{\partial g_2}{\partial x} = -2x/9\); ที่ (1, 2): \(-2/9 = -0.222\)

\(\frac{\partial g_2}{\partial y} = (4 - 2y)/4\); ที่ (1, 2): \(0/4 = 0\)

Sum row 2: \(0.222 + 0 = 0.222 \leq 1\) ✅

Convergence condition satisfied ✅

Iteration 1: ที่ (1, 2)

\(x_1 = g_1(1, 2) = (4(1) - 1^3 - 2)/4 = (4 - 1 - 2)/4 = 1/4 = 0.25\)

\(y_1 = g_2(1, 2) = -1/9 + (8 - 4)/4 + 1 = -0.111 + 1 + 1 = 1.889\)

\(\mathbf{x}^{(1)} = [0.25, 1.889]^T\)

Abs Err (2-norm): \(\sqrt{(0.25-1)^2 + (1.889-2)^2} = \sqrt{0.5625 + 0.01238} = 0.7579\)

Iteration 2: ที่ (0.25, 1.889)

\(x_2 = g_1(0.25, 1.889) = (1 - 0.015625 - 1.889)/4 = -0.9046/4 = -0.2262\)

\(y_2 = g_2(0.25, 1.889) = -0.0625/9 + (7.556 - 3.568)/4 + 1 = -0.00694 + 0.9970 + 1 = 1.9901\)

\(\mathbf{x}^{(2)} = [-0.2262, 1.9901]^T\)

Abs Err (2-norm): \(\sqrt{(-0.2262-0.25)^2 + (1.9901-1.889)^2} = \sqrt{0.2264 + 0.01023} = 0.4864\)

⚠️ สังเกตว่า Fixed-point ไม่ converge ไปที่ solution ที่ \((1.224, 1.833)\) — อาจ oscillate หรือ converge ไป solution อื่น (เช่น \((-1.86, -1.47)\)) เพราะ \(g_1, g_2\) ที่ให้อาจไม่ใช่ optimal iteration functions สำหรับ point นี้

เปรียบเทียบ Newton vs Fixed-Point:

วิธี\(\mathbf{x}^{(1)}\)\(\mathbf{x}^{(2)}\)Abs Err (iter 2)
Newton(1.276, 1.828)(1.224, 1.826)0.0514
Fixed-Point(0.25, 1.889)(-0.226, 1.990)0.4864

Newton converge เร็วและใกล้ solution จริง มาก, Fixed-Point ในกรณีนี้ไม่ค่อยดี

🖼️ ภาพรวม Solution

ระบบนี้เป็นการหาจุดตัดของ 2 curves:

  • \(y = x^3\) (cubic curve)
  • \(4x^2 + 9y^2 = 36\) (ellipse ที่มี semi-axes \(a=3, b=2\))

จุดตัด (solutions) มีหลายจุด รวมทั้ง \((1.224, 1.833)\) และ symmetric points อื่น ๆ

Python Code Implementation

import numpy as np

# ------ Newton's Method ------
def f(x, y):
    return np.array([y - x**3, 4*x**2 + 9*y**2 - 36])

def J(x, y):
    return np.array([[-3*x**2, 1], [8*x, 18*y]])

x_current = np.array([1.0, 2.0])
for k in range(10):
    fv = f(*x_current)
    Jv = J(*x_current)
    delta = np.linalg.solve(Jv, -fv)  # J·delta = -f
    x_current = x_current + delta
    print(f"Iter {k+1}: x = {x_current}, ||delta|| = {np.linalg.norm(delta):.6f}")

# ------ Fixed-Point Method ------
def g1(x, y): return (4*x - x**3 - y) / 4
def g2(x, y): return -x**2/9 + (4*y - y**2)/4 + 1

x_fp = np.array([1.0, 2.0])
for k in range(10):
    x_new = np.array([g1(*x_fp), g2(*x_fp)])
    print(f"FP Iter {k+1}: x = {x_new}")
    x_fp = x_new
