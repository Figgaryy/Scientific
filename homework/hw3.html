📝 HW3: Jacobi & Gauss-Seidel Methods

Assignment 3 — Update formulas, Matrix \(T\) & vector \(\mathbf{c}\), 2 iterations manually

🔗 หัวข้อที่เกี่ยวข้อง

อ่านทบทวน บทที่ 4 — Iterative Methods — Jacobi, Gauss-Seidel, สูตร Matrix Form

Problem 1 — Linear System 3×3

ระบบสมการ:

\[ \begin{aligned} 4x_1 + 3x_2 &= 1 \\ 3x_1 + 4x_2 - x_3 &= 0 \\ -x_2 + 4x_3 &= 1 \end{aligned} \]

(a) Update Formula (Component-wise) + 2 Iterations

ใช้ \(\mathbf{x}^{(0)} = [0, 0, 0]^T\); ทำ 2 iterations ด้วย:

  • (i) Jacobi method
  • (ii) Gauss-Seidel method

(b) Construct Matrix \(T\) และ Vector \(\mathbf{c}\)

สำหรับ update formula \(\mathbf{x}^{(k)} = T\mathbf{x}^{(k-1)} + \mathbf{c}\) โดยใช้:

  • (i) Jacobi method
  • (ii) Gauss-Seidel method

✅ Guided Solution

Setup

\(A = \begin{bmatrix}4&3&0\\3&4&-1\\0&-1&4\end{bmatrix}\), \(\mathbf{b} = \begin{bmatrix}1\\0\\1\end{bmatrix}\)

แยก \(A = D + L + U\):

\[ D = \begin{bmatrix}4&0&0\\0&4&0\\0&0&4\end{bmatrix}, L = \begin{bmatrix}0&0&0\\3&0&0\\0&-1&0\end{bmatrix}, U = \begin{bmatrix}0&3&0\\0&0&-1\\0&0&0\end{bmatrix} \]

(a)(i) Jacobi — Component-wise + 2 iterations

สูตร:

\[ \begin{aligned} x_1^{(k+1)} &= \frac{1}{4}(1 - 3x_2^{(k)}) \\ x_2^{(k+1)} &= \frac{1}{4}(0 - 3x_1^{(k)} + x_3^{(k)}) \\ x_3^{(k+1)} &= \frac{1}{4}(1 + x_2^{(k)}) \end{aligned} \]

Iteration 1: \(\mathbf{x}^{(0)} = [0, 0, 0]\)

  • \(x_1^{(1)} = (1 - 0)/4 = 0.25\)
  • \(x_2^{(1)} = (0 - 0 + 0)/4 = 0\)
  • \(x_3^{(1)} = (1 + 0)/4 = 0.25\)

\(\mathbf{x}^{(1)} = [0.25, 0, 0.25]^T\)

Iteration 2: ใช้ \(\mathbf{x}^{(1)}\):

  • \(x_1^{(2)} = (1 - 3 \cdot 0)/4 = 0.25\)
  • \(x_2^{(2)} = (0 - 3 \cdot 0.25 + 0.25)/4 = -0.125\)
  • \(x_3^{(2)} = (1 + 0)/4 = 0.25\)

\(\mathbf{x}^{(2)} = [0.25, -0.125, 0.25]^T\)

(a)(ii) Gauss-Seidel — Component-wise + 2 iterations

สูตร:

\[ \begin{aligned} x_1^{(k+1)} &= \frac{1}{4}(1 - 3x_2^{(k)}) \\ x_2^{(k+1)} &= \frac{1}{4}(0 - 3x_1^{(k+1)} + x_3^{(k)}) \\ x_3^{(k+1)} &= \frac{1}{4}(1 + x_2^{(k+1)}) \end{aligned} \]

Iteration 1: \(\mathbf{x}^{(0)} = [0, 0, 0]\)

  • \(x_1^{(1)} = 1/4 = 0.25\)
  • \(x_2^{(1)} = (0 - 3 \cdot 0.25 + 0)/4 = -0.1875\)
  • \(x_3^{(1)} = (1 - 0.1875)/4 = 0.2031\)

Iteration 2: ใช้ \(\mathbf{x}^{(1)}\):

  • \(x_1^{(2)} = (1 - 3(-0.1875))/4 = (1 + 0.5625)/4 = 0.3906\)
  • \(x_2^{(2)} = (0 - 3(0.3906) + 0.2031)/4 = (-1.1718 + 0.2031)/4 = -0.2422\)
  • \(x_3^{(2)} = (1 - 0.2422)/4 = 0.1895\)

\(\mathbf{x}^{(2)} = [0.3906, -0.2422, 0.1895]^T\)

สังเกตว่า Gauss-Seidel เข้าใกล้ solution แท้จริง (\([0.4174, -0.2432, 0.1892]^T\)) เร็วกว่า Jacobi

(b)(i) Jacobi Matrix Form

\(T = -D^{-1}(L+U)\); \(D^{-1} = \text{diag}(1/4, 1/4, 1/4)\)

\[ L + U = \begin{bmatrix}0&3&0\\3&0&-1\\0&-1&0\end{bmatrix} \] \[ T_J = -\frac{1}{4}(L+U) = \begin{bmatrix}0&-3/4&0\\-3/4&0&1/4\\0&1/4&0\end{bmatrix} \] \[ \mathbf{c}_J = D^{-1}\mathbf{b} = \begin{bmatrix}1/4\\0\\1/4\end{bmatrix} \]

(b)(ii) Gauss-Seidel Matrix Form

\(T_{GS} = -(D+L)^{-1}U\); \(\mathbf{c}_{GS} = (D+L)^{-1}\mathbf{b}\)

คำนวณ \((D+L)^{-1}\) โดย forward substitution row-by-row:

\[ (D+L)^{-1} = \begin{bmatrix}1/4&0&0\\-3/16&1/4&0\\-3/64&1/16&1/4\end{bmatrix} \]
\[ T_{GS} = -\begin{bmatrix}1/4&0&0\\-3/16&1/4&0\\-3/64&1/16&1/4\end{bmatrix}\begin{bmatrix}0&3&0\\0&0&-1\\0&0&0\end{bmatrix} = \begin{bmatrix}0&-3/4&0\\0&9/16&1/4\\0&9/64&1/16\end{bmatrix} \] \[ \mathbf{c}_{GS} = \begin{bmatrix}1/4\\-3/16\\13/64\end{bmatrix} \]

🔬 Optional: Programming — Linear System 4×4

Implement Jacobi และ Gauss-Seidel เพื่อประมาณ solution:

\[ \begin{aligned} 12x_1 + x_2 + 2x_3 + x_4 &= 12 \\ x_1 + 6x_2 - x_3 + x_4 &= 14 \\ 2x_1 + 15x_3 - x_4 &= -13 \\ x_1 + 2x_2 + 9x_4 &= 5 \end{aligned} \]

Initial: \(\mathbf{x}^{(0)} = [1, 1, 1, 1]^T\); Stopping criterion: residual < \(10^{-4}\)

สูตร Update สำหรับ Jacobi:

\[ \begin{aligned} x_1^{(k+1)} &= \frac{1}{12}(12 - x_2^{(k)} - 2x_3^{(k)} - x_4^{(k)}) \\ x_2^{(k+1)} &= \frac{1}{6}(14 - x_1^{(k)} + x_3^{(k)} - x_4^{(k)}) \\ x_3^{(k+1)} &= \frac{1}{15}(-13 - 2x_1^{(k)} + x_4^{(k)}) \\ x_4^{(k+1)} &= \frac{1}{9}(5 - x_1^{(k)} - 2x_2^{(k)}) \end{aligned} \]

Iteration 1 (Jacobi):

  • \(x_1^{(1)} = (12 - 1 - 2 - 1)/12 = 0.6667\)
  • \(x_2^{(1)} = (14 - 1 + 1 - 1)/6 = 2.1667\)
  • \(x_3^{(1)} = (-13 - 2 + 1)/15 = -0.9333\)
  • \(x_4^{(1)} = (5 - 1 - 2)/9 = 0.2222\)

Gauss-Seidel converge เร็วกว่า Jacobi (~6 vs 8 iterations สำหรับ residual < \(10^{-4}\))

Python Code Example:

import numpy as np
A = np.array([[12,1,2,1],[1,6,-1,1],[2,0,15,-1],[1,2,0,9]], dtype=float)
b = np.array([12,14,-13,5], dtype=float)
x = np.ones(4)
for k in range(100):
    x_new = np.zeros(4)
    for i in range(4):
        # Gauss-Seidel: use x_new[j] for ji
        s = b[i] - sum(A[i,j]*x_new[j] for j in range(i)) \
                 - sum(A[i,j]*x[j] for j in range(i+1,4))
        x_new[i] = s / A[i,i]
    if np.linalg.norm(A @ x_new - b) < 1e-4:
        break
    x = x_new
print(f"Converged in {k+1} iterations: {x_new}")
