💡 Trick & Pitfalls สำคัญ

🔤 บทที่ 1: Taylor's Remainder

  • Trick: ในการหา max error ให้ bound \(|f^{(n+1)}(\xi)|\) ด้วย max ในช่วง — สำหรับ \(\sin, \cos\) → bound = 1; สำหรับ \(e^x\) กับ \(x > 0\) → bound = \(e^x\); กับ \(x < 0\) → bound = 1
  • Pitfall: อย่าลืม factorial \((n+1)!\); ข้อสอบชอบเปลี่ยน degree (n) กับ number of terms (n+1)
  • Formula: \(|R_{n+1}(x)| \leq \frac{M}{(n+1)!}|x-c|^{n+1}\) โดย \(M = \max |f^{(n+1)}(\xi)|\)

🎯 บทที่ 2: Root Finding

  • Trick: Bisection # iterations: \(n > \log_2\left(\frac{b-a}{TOL}\right)\)
  • Trick: Newton ต้อง \(f'(x)\) ที่มีอนุพันธ์อยู่ใน initial guess
  • Trick: False Position vs Bisection ต่างที่สูตร: \(x = \frac{a f(b) - b f(a)}{f(b) - f(a)}\)
  • Pitfall: Newton อาจ diverge ถ้า \(f'(x_j) \approx 0\); Fixed-point ต้องตรวจ \(|g'(x)| < 1\) รอบราก
  • Pitfall: Residual = \(|f(\tilde{x})|\), Abs error = \(|\tilde{x}_j - \tilde{x}_{j-1}|\) — ไม่เหมือนกัน!

🔷 บทที่ 3: Linear Iterative

  • Trick: Jacobi ใช้ \(x^{(k)}\) ทั้งหมด; Gauss-Seidel ใช้ \(x^{(k+1)}\) ทันทีเมื่อคำนวณได้
  • Trick: \(T_J = -D^{-1}(L+U)\); \(T_{GS} = -(D+L)^{-1}U\); \(T_\omega = (D+\omega L)^{-1}[(1-\omega)D - \omega U]\)
  • Trick: ถ้าโจทย์ให้ SOR ω = 1 → เท่ากับ Gauss-Seidel
  • Pitfall: เขียน L (strictly lower) และ U (strictly upper) — ไม่รวม diagonal

⚡ บทที่ 4: Nonlinear Systems

  • Trick: Newton สำหรับระบบ: \(J \Delta x = -f\) แล้วบวก step \(x^{(k+1)} = x^{(k)} + \Delta x\)
  • Trick: Inverse 2×2: \(\frac{1}{\det}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\) จำให้ขึ้นใจ
  • Trick: Cramer's Rule ง่ายสำหรับ 2×2, 3×3 — ประหยัดเวลาสอบ
  • Pitfall: Fixed-point ที่ divergence — ต้องเลือก g(x) ที่มี \(|\partial g/\partial x| + |\partial g/\partial y| < 1\)

📊 บทที่ 5 (สอบ) / บทที่ 6 (จริง): Regression

  • Trick: จำสูตรสำเร็จ \(a_1 = \frac{nS_{xy} - S_x S_y}{n S_{xx} - S_x^2}\); \(a_0 = \bar{y} - a_1 \bar{x}\)
  • Trick: Nonlinear form → Linear: Power ใช้ ln ทั้งสองข้าง, Exp ใช้ ln เฉพาะ y, Reciprocal ใช้ 1/y
  • Trick: R² = 1 - SSres/SStot; ค่าใกล้ 1 → fit ดี
  • Pitfall: Quadratic regression = 3×3 matrix system (m+1 = 3); อย่าใช้แค่สูตร a₀, a₁
