Formula Sheet — CSS322 Midterm (หน้า 1/2)

Ch1 Taylor · Ch2 Roots · Ch3 Linear Iterative

Ch1: Taylor Series

Taylor: \(f(x) = \sum_{k=0}^n \frac{f^{(k)}(c)}{k!}(x-c)^k + R_{n+1}(x)\)

Remainder: \(R_{n+1}(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-c)^{n+1}\)

Max error: \(|R_{n+1}| \leq \frac{M|x-c|^{n+1}}{(n+1)!}\), \(M = \max |f^{(n+1)}(\xi)|\)

Common: \(e^x, \sin, \cos, \ln(1+x)\); \(c=0\) → Maclaurin

Errors: \(E_t = |x_\tau - \tilde x|\), \(\varepsilon_t = E_t/|x_\tau|\)

n-D.P.: \(|\text{err}| \leq 0.5 \times 10^{-n}\)

Ch2: Bisection

Condition: \(f(a)f(b) < 0\)

Update: \(\tilde x = (a+b)/2\)

Choose sub-interval by sign of \(f(a)f(\tilde x)\)

# iter: \(n > \log_2\left(\frac{b-a}{TOL}\right)\)

Error bound: \(|x_\tau - \tilde x_n| < \frac{b-a}{2^n}\)

Ch2: False Position

Update: \(\tilde x = \frac{a f(b) - b f(a)}{f(b) - f(a)}\)

Same interval choice as Bisection

Ch2: Newton-Raphson

\(x_{j+1} = x_j - \frac{f(x_j)}{f'(x_j)}\)

Converge if: \(f, f', f''\) cont., \(f'(x_\tau) \neq 0\), \(x_0\) close

Ch2: Secant

\(m_j = \frac{f(x_j) - f(x_{j-1})}{x_j - x_{j-1}}\)

\(x_{j+1} = x_j - \frac{f(x_j)}{m_j}\)

No derivative needed (2 initial values)

Ch2: Fixed-Point

Rewrite \(f(x)=0\) as \(x = g(x)\)

\(x_{i+1} = g(x_i)\)

Converge if: \(|g'(x)| \leq k < 1\) near root

Error: \(|x_n - x^*| \leq \frac{k^n}{1-k}|x_1 - x_0|\)

Ch3: Jacobi Method

Split: \(A = D + L + U\) (L strictly lower, U strictly upper)

Component: \(x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j \neq i} a_{ij}x_j^{(k)}\right)\)

Matrix: \(T_J = -D^{-1}(L+U), \; c_J = D^{-1}b\); \(x^{(k)} = T_J x^{(k-1)} + c_J\)

Ch3: Gauss-Seidel

Component: \(x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{ji} a_{ij}x_j^{(k)}\right)\)

Matrix: \(T_{GS} = -(D+L)^{-1}U, \; c_{GS} = (D+L)^{-1}b\)

Ch3: SOR (concept)

\(x_i^{(k)} = (1-\omega)x_i^{(k-1)} + \frac{\omega}{a_{ii}}\left(b_i - \sum_{ji} a_{ij}x_j^{(k-1)}\right)\)

Matrix: \(T_\omega = (D + \omega L)^{-1}[(1-\omega)D - \omega U], \; c_\omega = \omega(D+\omega L)^{-1}b\)

\(\omega = 1\) → Gauss-Seidel; \(0 < \omega < 1\) under; \(1 < \omega < 2\) over

Kahan: converge → \(0 < \omega < 2\); Ostrowski-Reich: A pos.def. + \(0<\omega<2\) → converge

Norms & Convergence

\(\|x\|_1 = \sum |x_i|\); \(\|x\|_2 = \sqrt{\sum x_i^2}\); \(\|x\|_\infty = \max |x_i|\)

\(\|A\|_\infty = \max_i \sum_j |a_{ij}|\); \(\|A\|_1 = \max_j \sum_i |a_{ij}|\)

Diagonally dominant: \(|a_{ii}| > \sum_{j\neq i} |a_{ij}| \; \forall i\) → Jacobi/GS converge เสมอ

Stop: \(\|x^{(k)} - x^{(k-1)}\| < TOL\) หรือ \(\|Ax^{(k)} - b\| < TOL\)

Formula Sheet — CSS322 Midterm (หน้า 2/2)

Ch4 Nonlinear · Ch5 Regression · Useful Identities

Ch4: Newton's Method for Systems

System: \(f(x) = 0, \; x = [x_1, \ldots, x_n]^T\)

Jacobian: \(J(x) = \left[\frac{\partial f_i}{\partial x_j}\right]\)

Update: \(x^{(i+1)} = x^{(i)} - J_i^{-1} f(x^{(i)})\), หรือ \(J_i \Delta x = -f(x^{(i)}), x^{(i+1)} = x^{(i)} + \Delta x\)

Inverse 2×2: \(\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1} = \frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\)

Cramer 2×2: \(\Delta x_1 = \frac{b_1 a_{22} - b_2 a_{12}}{a_{11} a_{22} - a_{21} a_{12}}\), similar for \(\Delta x_2\)

Ch4: Fixed-Point for Systems

Rewrite as \(x = g(x)\); update \(x^{(k)} = g(x^{(k-1)})\)

Converge condition: \(\sum_{j=1}^n \left|\frac{\partial g_i}{\partial x_j}\right| \leq 1\) \(\forall i\) near solution

Ch5: Linear Least-Squares Regression \(f(x) = a_0 + a_1 x\)

Solve \(\begin{bmatrix} n & S_x \\ S_x & S_{xx} \end{bmatrix} \begin{bmatrix} a_0 \\ a_1 \end{bmatrix} = \begin{bmatrix} S_y \\ S_{xy} \end{bmatrix}\)

\(a_1 = \frac{n S_{xy} - S_x S_y}{n S_{xx} - S_x^2}\), \(a_0 = \frac{S_{xx} S_y - S_{xy} S_x}{n S_{xx} - S_x^2} = \bar y - a_1 \bar x\)

\(S_x = \sum x_i, S_y = \sum y_i, S_{xx} = \sum x_i^2, S_{xy} = \sum x_i y_i\)

Ch5: Polynomial Regression (degree m)

\(f(x) = a_0 + a_1 x + \cdots + a_m x^m\)

Solve \((m+1) \times (m+1)\) system: entry \((i,j) = \sum x_k^{i+j-2}\), RHS \((i) = \sum y_k x_k^{i-1}\)

Quadratic: \(\begin{bmatrix} n & \sum x_i & \sum x_i^2 \\ \sum x_i & \sum x_i^2 & \sum x_i^3 \\ \sum x_i^2 & \sum x_i^3 & \sum x_i^4 \end{bmatrix} \mathbf{a} = \begin{bmatrix} \sum y_i \\ \sum x_i y_i \\ \sum x_i^2 y_i \end{bmatrix}\)

Ch5: R² (Goodness-of-Fit)

\(\bar y = \frac{1}{n}\sum y_i\)

\(SS_{tot} = \sum (y_i - \bar y)^2\)

\(SS_{res} = \sum (y_i - f(x_i))^2\)

\(R^2 = 1 - \frac{SS_{res}}{SS_{tot}}\)

Ch5: Nonlinear Linearization

Power \(y = bx^m\): \(Y = \ln y, X = \ln x\); \(b = e^{a_0}, m = a_1\)

Exp \(y = be^{mx}\): \(Y = \ln y, X = x\); \(b = e^{a_0}, m = a_1\)

Recip \(y = \frac{1}{mx+b}\): \(Y=1/y, X=x\); \(b = a_0, m = a_1\)

Recip 2 \(y = \frac{x}{mx+b}\): \(Y=1/y, X=1/x\); \(b = a_1, m = a_0\)

🔧 Useful Identities & Values

Common Derivatives: \((\sin x)' = \cos x\), \((\cos x)' = -\sin x\), \((e^x)' = e^x\), \((\ln x)' = 1/x\), \((x^n)' = n x^{n-1}\)

Values: \(e^0=1, e^{-0.1} \approx 0.9048, e^{0.1} \approx 1.1052, \ln 2 \approx 0.693, \pi \approx 3.1416\)

Sums: \(\sum_{k=1}^n k = n(n+1)/2\), \(\sum_{k=1}^n k^2 = n(n+1)(2n+1)/6\)

Factorials: \(0!=1, 1!=1, 2!=2, 3!=6, 4!=24, 5!=120, 6!=720, 7!=5040\)
