Q1

Ch1 · Taylor Series Convergence

15 คะแนน

จำนวน terms ที่ต้องใช้ใน Taylor series ของ \(f(x) = \ln(1+x)\) รอบ \(x = 0\) เพื่อประมาณ \(\ln(1.2)\) ให้แม่นยำถึง \(10^{-3}\) คือกี่ terms? (\(n+1\))

คำตอบ:

✅ เฉลย

\(f^{(k)}(x) = (-1)^{k-1}(k-1)!/(1+x)^k\); ที่ \(\xi \in (0, 0.2)\), \(|f^{(n+1)}(\xi)| \leq n!\)

Remainder: \(|R_{n+1}(0.2)| \leq \frac{n!}{(n+1)!}(0.2)^{n+1} = \frac{(0.2)^{n+1}}{n+1}\)

ต้อง \(\frac{(0.2)^{n+1}}{n+1} \leq 10^{-3}\):

  • \(n = 2\): \((0.2)^3/3 = 0.008/3 = 0.00267\) ❌
  • \(n = 3\): \((0.2)^4/4 = 0.0016/4 = 0.0004 < 10^{-3}\) ✅

ตอบ: \(n = 3\) → ใช้ \(n + 1 = 4\) terms

Q2

Ch2 · False Position Method

15 คะแนน

ใช้ False Position หา root ของ \(f(x) = e^x - 3x = 0\) บน \([0, 1]\) — คำนวณ \(x_1\)

คำตอบ:

✅ เฉลย

\(f(0) = 1 - 0 = 1 > 0\); \(f(1) = e - 3 = -0.2817 < 0\) → root ใน [0, 1]

\(x_1 = \frac{a f(b) - b f(a)}{f(b) - f(a)} = \frac{0 \cdot (-0.2817) - 1 \cdot 1}{-0.2817 - 1} = \frac{-1}{-1.2817} = 0.7802\)

⚠️ Recheck expected answer: \(x_1 = 0.7802\) (คำนวณจริง)

ค่าจริงในหน้าเฉลยควรเป็น 0.7802 — ทดสอบดูว่าตอบ 0.7802 (tol=0.005)

คำตอบที่ถูก: \(x_1 \approx 0.7802\)

Q3

Ch2 · Fixed-Point Convergence

10 คะแนน

สำหรับ \(f(x) = x^2 - 2 = 0\) พิจารณา iteration functions:

(I) \(g_1(x) = x^2 + x - 2\)

(II) \(g_2(x) = 2/x\)

(III) \(g_3(x) = (x + 2/x)/2\)

ตัวใดที่มี \(|g'(x^*)| < 1\) ที่ root \(x^* = \sqrt{2}\) → converge?

✅ เฉลย

ที่ \(x^* = \sqrt{2} \approx 1.414\):

(I) \(g_1'(x) = 2x + 1\); \(g_1'(\sqrt{2}) = 2\sqrt{2} + 1 \approx 3.83\) → |g'| > 1 → Diverge ❌

(II) \(g_2'(x) = -2/x^2\); \(g_2'(\sqrt{2}) = -2/2 = -1\) → \(|g'| = 1\) → ไม่ converge (borderline) ❌

(III) \(g_3'(x) = (1 - 2/x^2)/2\); \(g_3'(\sqrt{2}) = (1 - 1)/2 = 0\) → Converge quadratically ✅

(III) จริงๆ คือ Newton's method สำหรับ \(f(x) = x^2 - 2\)!

Ch3 · Gauss-Seidel (3×3)

15 คะแนน

ใช้ Gauss-Seidel กับระบบ:

\[ 10x_1 + x_2 = 11, \; x_1 + 10x_2 + x_3 = 12, \; x_2 + 10x_3 = 11 \]

\(x^{(0)} = [0, 0, 0]^T\) หา \(x^{(1)}\):

✅ เฉลย

\(x_1^{(1)} = (11 - 0)/10 = 1.1\)

\(x_2^{(1)} = (12 - 1.1 - 0)/10 = 10.9/10 = 1.09\)

\(x_3^{(1)} = (11 - 1.09)/10 = 9.91/10 = 0.991\)

Matrix diagonally dominant → converge; solution แท้จริง \([1, 1, 1]^T\)

Ch4 · Newton's Method for Systems

15 คะแนน

ระบบ: \(f_1 = x + y - 3 = 0\), \(f_2 = x^2 + y^2 - 9 = 0\)

\((x_0, y_0) = (2, 2)\); ทำ 1 iteration ของ Newton

✅ เฉลย

\(J = \begin{bmatrix} 1 & 1 \\ 2x & 2y \end{bmatrix}\); ที่ \((2,2)\): \(J = \begin{bmatrix} 1 & 1 \\ 4 & 4 \end{bmatrix}\)

⚠️ \(\det J = 4 - 4 = 0\) → J singular! Newton fails at (2, 2)

ในทางปฏิบัติ ต้องเลือก initial อื่น เช่น (2.5, 1) หรือ (1, 2.5)

ที่ solution จริง: \(x + y = 3\) และ \(x^2 + y^2 = 9\) → \((x, y) = (0, 3)\) หรือ \((3, 0)\)

Note: โจทย์นี้แสดงว่า Newton อาจใช้ไม่ได้ ถ้า Jacobian singular ที่ initial

Q6

Ch4 · Fixed-Point Convergence (System)

15 คะแนน

ให้ระบบ \(x = g_1(x, y), y = g_2(x, y)\) ที่ \((x^*, y^*) = (0.5, 0.5)\)

Partial derivatives ที่ solution: \(\frac{\partial g_1}{\partial x} = 0.2, \frac{\partial g_1}{\partial y} = 0.3\); \(\frac{\partial g_2}{\partial x} = 0.4, \frac{\partial g_2}{\partial y} = 0.5\)

Fixed-point iteration จะ converge หรือไม่?

✅ เฉลย

เงื่อนไข: \(\sum_j |\partial g_i / \partial x_j| \leq 1\) สำหรับทุก \(i\)

Row 1: \(|0.2| + |0.3| = 0.5 \leq 1\) ✅

Row 2: \(|0.4| + |0.5| = 0.9 \leq 1\) ✅

ทั้ง 2 rows ผ่านเงื่อนไข → Converge ✅

Ch5 · Quadratic Regression

15 คะแนน

ให้ข้อมูล:

x012
y137

Fit \(f(x) = a_0 + a_1 x + a_2 x^2\) โดยใช้ least-squares (regression exact เพราะ 3 จุด, 3 unknowns)

✅ เฉลย

เนื่องจากมี 3 จุด 3 unknowns → fit ผ่านทุกจุดพอดี (interpolation)

\(f(0) = a_0 = 1\); \(f(1) = a_0 + a_1 + a_2 = 3\); \(f(2) = a_0 + 2a_1 + 4a_2 = 7\)

จากสมการ 1: \(a_0 = 1\); แทนใน 2: \(a_1 + a_2 = 2\); ใน 3: \(2a_1 + 4a_2 = 6\)

Solve: \(a_1 + a_2 = 2\) และ \(a_1 + 2a_2 = 3\) → \(a_2 = 1, a_1 = 1\)

\(f(x) = 1 + x + x^2\)

ตรวจ: \(f(0)=1, f(1)=3, f(2)=7\) ✅
