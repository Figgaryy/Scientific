บทที่ 8: Spline Interpolation (Piecewise)

ใช้หลาย polynomial degree ต่ำบน sub-intervals แทน polynomial เดียว degree สูง — แก้ Runge's phenomenon

🎯 เป้าหมายของบท
  • เข้าใจแนวคิด Piecewise polynomial และ knots
  • สร้าง Linear Spline (degree 1), Quadratic Spline (degree 2), Cubic Spline (degree 3)
  • ใช้ Natural และ Clamped boundary conditions
  • แก้ระบบ tridiagonal สำหรับ cubic spline

1. Introduction

Spline function ของ degree \(k\): piecewise polynomial degree \(\leq k\) ที่

  • ผ่านทุก data points (knots): \(a = x_1 < x_2 < \cdots < x_n = b\)
  • อนุพันธ์ \((k-1)\)-th ต่อเนื่องบน \([a, b]\)

2. Linear Spline (degree 1)

สำหรับ \(n\) data points → \(n - 1\) linear segments:

\[ S_i(x) = y_i + \left(\frac{y_{i+1} - y_i}{x_{i+1} - x_i}\right)(x - x_i), \quad i = 1, \ldots, n-1 \]

คือการต่อเส้นตรงระหว่างจุดต่อเนื่อง — เหมือน dot-to-dot

ตัวอย่าง 2.1 Linear Spline ▶

โจทย์: data: \((0,1), (1,-2), (3,4), (5,-6)\); ประมาณ \(y(2)\)

มี 3 linear segments:

\(S_1(x) = 1 + \frac{-2-1}{1-0}(x-0) = 1 - 3x\) สำหรับ \(x \in [0, 1]\)

\(S_2(x) = -2 + \frac{4-(-2)}{3-1}(x-1) = -2 + 3(x-1)\) สำหรับ \(x \in [1, 3]\)

\(S_3(x) = 4 + \frac{-6-4}{5-3}(x-3) = 4 - 5(x-3)\) สำหรับ \(x \in [3, 5]\)

\(x = 2 \in [1, 3]\) → \(S_2(2) = -2 + 3(1) = 1\)

3. Quadratic Spline (degree 2)

สำหรับ \(n\) data points → \(n - 1\) quadratic segments:

\[ S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 \]

เงื่อนไข: ต้องการ \(3(n-1)\) unknowns เงื่อนไข:

  1. \(S_i(x_i) = y_i\) และ \(S_i(x_{i+1}) = y_{i+1}\) → \(2(n-1)\) สมการ
  2. \(S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})\) → \(n-2\) สมการ (continuity ของ 1st derivative)
  3. Boundary: ต้องเพิ่ม 1 เงื่อนไข (เช่น \(S_1''(x_1) = 0\) — Natural)

3.1 สูตรง่าย ๆ สำหรับคำนวณ

ตั้ง \(z_i = S_i'(x_i)\); \(h_i = x_{i+1} - x_i\):

\[ z_{i+1} = -z_i + 2\left(\frac{y_{i+1} - y_i}{h_i}\right) \]

ด้วย \(z_1\) ที่ต้องกำหนด (Natural: \(z_1 = z_2\))

Polynomial สุดท้าย:

\[ S_i(x) = y_i + z_i(x - x_i) + \left(\frac{z_{i+1} - z_i}{2 h_i}\right)(x - x_i)^2 \]
ตัวอย่าง 3.1 Quadratic Spline ▶

โจทย์: data: \((1,2), (2,3), (3,5)\), \(S'(1) = 2\)

\(h_1 = 1, h_2 = 1\); \(z_1 = 2\) (given)

\(z_2 = -2 + 2(3-2)/1 = 0\); \(z_3 = -0 + 2(5-3)/1 = 4\)

\(S_1(x) = 2 + 2(x-1) + \frac{0-2}{2}(x-1)^2 = 2 + 2(x-1) - (x-1)^2\), \(x \in [1,2]\)

\(S_2(x) = 3 + 0(x-2) + \frac{4-0}{2}(x-2)^2 = 3 + 2(x-2)^2\), \(x \in [2,3]\)

4. Cubic Spline (degree 3) ⭐

Smoothest + accurate — วิธีมาตรฐาน สำหรับ interpolation

\[ S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3 \]

เงื่อนไข (คง \(S, S', S''\) ต่อเนื่อง):

  1. \(S_i(x_i) = y_i, S_i(x_{i+1}) = y_{i+1}\) — ผ่านทุกจุด
  2. \(S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})\) — 1st derivative ต่อเนื่อง
  3. \(S_i''(x_{i+1}) = S_{i+1}''(x_{i+1})\) — 2nd derivative ต่อเนื่อง

4.1 ระบบ Tridiagonal สำหรับหา \(z_i = S_i''(x_i)\)

\[ h_{i-1} z_{i-1} + 2(h_{i-1} + h_i) z_i + h_i z_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right) \]

สำหรับ \(i = 2, \ldots, n-1\) → ได้ \(n - 2\) สมการ, \(n\) unknowns → ต้องการ 2 boundary conditions

4.2 Boundary Conditions

Natural Boundary

\(S''(x_1) = S''(x_n) = 0\)

→ \(z_1 = 0, z_n = 0\)

⭐ นิยมใช้ที่สุด

Clamped Boundary

\(S'(x_1) = \alpha, S'(x_n) = \beta\)

ใช้เมื่อรู้ค่า \(f'(x)\) ที่ปลาย

4.3 Coefficients หลังได้ \(z_i\)

\[ a_i = y_i, \quad c_i = \frac{z_i}{2}, \quad d_i = \frac{z_{i+1} - z_i}{6 h_i} \] \[ b_i = \frac{y_{i+1} - y_i}{h_i} - h_i\left(\frac{z_{i+1}}{6} + \frac{z_i}{3}\right) \]
ตัวอย่าง 4.1 Natural Cubic Spline ▶

โจทย์: data: \((1,2), (2,3), (3,5)\) — Natural cubic spline

\(h_1 = h_2 = 1\); Natural: \(z_1 = z_3 = 0\)

ระบบ: สำหรับ \(i = 2\):

\(1 \cdot z_1 + 2(1+1) \cdot z_2 + 1 \cdot z_3 = 6\left(\frac{5-3}{1} - \frac{3-2}{1}\right)\)

\(4 z_2 = 6(1) = 6 \Rightarrow z_2 = 1.5\)

Coefficients:

\(S_1\) (\(i=1\)): \(a_1 = 2, c_1 = 0, d_1 = (1.5-0)/6 = 0.25\); \(b_1 = 1 - (1/6 + 0) = 0.75\)

\(S_1(x) = 2 + 0.75(x-1) + 0.25(x-1)^3\), \(x \in [1,2]\)

\(S_2\) (\(i=2\)): \(a_2 = 3, c_2 = 0.75, d_2 = (0-1.5)/6 = -0.25\); \(b_2 = 2 - (0 + 0.5) = 1.5\)

\(S_2(x) = 3 + 1.5(x-2) + 0.75(x-2)^2 - 0.25(x-2)^3\), \(x \in [2,3]\)

5. เปรียบเทียบ Spline Types

SplineDegreeContinuitySmoothnessใช้เมื่อ

Quadratic2\(S, S'\)Smooth-ishIntermediate
Cubic ⭐3\(S, S', S''\)Very smoothStandard choice
