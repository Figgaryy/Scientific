บทที่ 8: Spline Interpolation (Piecewise)

ใช้หลาย polynomial degree ต่ำบน sub-intervals แทน polynomial เดียว degree สูง — แก้ Runge's phenomenon

🎯 เป้าหมายของบท
  • เข้าใจแนวคิด Piecewise polynomial และ knots
  • สร้าง Linear Spline (degree 1), Quadratic Spline (degree 2), Cubic Spline (degree 3)
  • ใช้ Natural และ Clamped boundary conditions
  • แก้ระบบ tridiagonal สำหรับ cubic spline

🧮 บทนี้ใช้ fx-991EX ช่วยได้ ดูปุ่มทีละขั้นที่ หน้าใช้เครื่องคิดเลข

1. Introduction

Spline function ของ degree \(k\): piecewise polynomial degree \(\leq k\) ที่

  • ผ่านทุก data points (knots): \(a = x_1 < x_2 < \cdots < x_n = b\)
  • อนุพันธ์ \((k-1)\)-th ต่อเนื่องบน \([a, b]\)
จากคาบเรียน: ทำไมต้อง spline และเงื่อนไขสองข้ออ่านยังไง
คาบ 12 ต.ค. · คลิป 1 · 11:44–14:43
  • ต่อจากบทที่ 7: ถ้ามี \(n\) จุดแล้วใช้ polynomial เดียว degree \(n-1\) พอจุดเยอะ degree ก็สูงตาม กราฟจะแกว่งมาก spline แก้โดยล็อก degree ไว้ แล้วต่อจุดทีละคู่ที่อยู่ติดกัน วิชานี้เรียนแค่ degree 1, 2, 3 คือ linear, quadratic และ cubic spline
  • เงื่อนไขข้อแรกเขียนว่า degree "\(\le k\)" อาจารย์ย้ำว่า "k or less" เช่น quadratic spline แต่ละช่วงจะเป็น degree 2 หรือ degree 1 ก็ได้ (ตัวอย่างในคาบ 2.2 ข้างล่างมีช่วงหนึ่งเป็นเส้นตรง)
  • เงื่อนไขข้อสองไล่ตาม \(k\): \(k = 1\) ต้องการแค่ตัวฟังก์ชันต่อเนื่อง (อนุพันธ์อันดับ 0), \(k = 2\) ต้องให้ \(S'\) ต่อเนื่องด้วย, \(k = 3\) ต้องให้ทั้ง \(S'\) และ \(S''\) ต่อเนื่อง

2. Linear Spline (degree 1)

สำหรับ \(n\) data points → \(n - 1\) linear segments:

\[ S_i(x) = y_i + \left(\frac{y_{i+1} - y_i}{x_{i+1} - x_i}\right)(x - x_i), \quad i = 1, \ldots, n-1 \]

คือการต่อเส้นตรงระหว่างจุดต่อเนื่อง — เหมือน dot-to-dot

จากคาบเรียน: สูตร linear spline มาจากไหน
คาบ 12 ต.ค. · คลิป 1 · 15:05–27:09
  1. \(n\) จุดมี \(n-1\) ช่วง จึงมี \(S_1, S_2, \dots, S_{n-1}\) ตัว \(S_i\) ใช้กับช่วง \([x_i, x_{i+1}]\) เท่านั้น
  2. อาจารย์เขียน \(S_i\) ในรูปเดียวกับ Newton degree 1: \(S_i(x) = a_i + b_i(x - x_i)\)
  3. บังคับ \(S_i(x_i) = y_i\) พจน์ที่สองหายเพราะ \(x_i - x_i = 0\) ได้ \(a_i = y_i\)
  4. บังคับ \(S_i(x_{i+1}) = y_{i+1}\) แล้วแทน \(a_i = y_i\) ได้ \(b_i = \dfrac{y_{i+1} - y_i}{x_{i+1} - x_i}\) ซึ่งก็คือ slope ของเส้นตรงช่วงนั้น
  5. ได้สูตรโดยไม่ต้องแก้ linear system เลย แค่แทน data

ในเอกสาร note สูตรนี้พิมพ์ตัวส่วนผิดเป็น \(x - x_i\) อาจารย์แจ้งในคาบให้แก้เป็น \(x_{i+1} - x_i\) เพราะถ้ามี \(x\) อยู่ในตัวส่วน \(S_i\) จะไม่ใช่เส้นตรง ใครคัดสูตรจาก note ลง cheat sheet ให้แก้ตรงนี้ด้วย (สูตรบนหน้านี้ถูกแล้ว)

ตัวอย่าง 2.1 Linear Spline ▶

โจทย์: data: \((0,1), (1,-2), (3,4), (5,-6)\); ประมาณ \(y(2)\)

มี 3 linear segments:

\(S_1(x) = 1 + \frac{-2-1}{1-0}(x-0) = 1 - 3x\) สำหรับ \(x \in [0, 1]\)

\(S_2(x) = -2 + \frac{4-(-2)}{3-1}(x-1) = -2 + 3(x-1)\) สำหรับ \(x \in [1, 3]\)

\(S_3(x) = 4 + \frac{-6-4}{5-3}(x-3) = 4 - 5(x-3)\) สำหรับ \(x \in [3, 5]\)

\(x = 2 \in [1, 3]\) → \(S_2(2) = -2 + 3(1) = 1\)

จุดรอยต่อใช้ช่วงไหน และต้องหาครบทุกช่วงไหม
คาบ 12 ต.ค. · คลิป 1 · 30:32–37:43
  • เขียนช่วงแบบปิด \([0,1]\) กับ \([1,3]\) แล้ว \(x = 1\) อยู่ทั้งสองช่วง ไม่ผิด เพราะ \(S_1(1) = S_2(1) = -2\) ซึ่งเป็น data point ที่โจทย์ให้มา จะใช้ตัวไหนก็ได้ค่าเดียวกัน
  • โจทย์ถามแค่ \(y\) ที่ \(x = 2\) ก็สร้างแค่ \(S_2\) พอ ไม่ต้องหา \(S_1\) กับ \(S_3\) แต่ถ้าโจทย์ให้หา spline function ต้องเขียนครบทุกช่วง
  • โปรแกรมพล็อตกราฟส่วนใหญ่ลากเส้นตรงต่อจุดแบบนี้ ซูมเข้าไปจะเห็นมุมหักตรงรอยต่อ ตรงมุมนั้นหาอนุพันธ์ไม่ได้ จึงต้องขยับไป quadratic

3. Quadratic Spline (degree 2)

สำหรับ \(n\) data points → \(n - 1\) quadratic segments:

\[ S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 \]

เงื่อนไข: ต้องการ \(3(n-1)\) unknowns เงื่อนไข:

  1. \(S_i(x_i) = y_i\) และ \(S_i(x_{i+1}) = y_{i+1}\) → \(2(n-1)\) สมการ
  2. \(S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})\) → \(n-2\) สมการ (continuity ของ 1st derivative)
  3. Boundary: ต้องเพิ่ม 1 เงื่อนไข (เช่น \(S_1''(x_1) = 0\) — Natural)
จากคาบเรียน: นับ unknown กับสมการ ทำไมขาดไป 1
คาบ 12 ต.ค. · คลิป 1 · 38:00–49:17, 55:14–56:58

อาจารย์ให้วาดสามจุดติดกัน \(x_i, x_{i+1}, x_{i+2}\) โดย \(S_i\) กับ \(S_{i+1}\) มาเจอกันที่จุดกลาง \(x_{i+1}\) ตรงจุดกลางนี้ทั้งสองชิ้นต้องให้ค่าเท่ากัน (เท่ากับ \(y_{i+1}\)) และ slope ต้องเท่ากันด้วย กราฟจึงต่อกันเรียบไม่มีมุมหัก

นับจำนวน:

  • unknown: แต่ละ \(S_i\) มี \(a_i, b_i, c_i\) และมี \(n-1\) ชิ้น รวม \(3(n-1) = 3n - 3\) ตัว
  • เงื่อนไขผ่านจุดปลายสองข้างของทุกชิ้น: \(2(n-1) = 2n - 2\) สมการ
  • เงื่อนไข slope เท่ากันที่จุดกลาง: มีจุดกลาง \(n-2\) จุด ได้ \(n-2\) สมการ
  • รวม \(3n - 4\) สมการ น้อยกว่า unknown อยู่ 1

อาจารย์จึงย้ำว่าโจทย์ quadratic spline ต้องให้เงื่อนไขเพิ่มมาอีก 1 ข้อเสมอ ไม่อย่างนั้นหา coefficient ให้ unique ไม่ได้ เงื่อนไขนี้อาจเป็นค่า \(S'(x_1)\) (แบบตัวอย่าง 3.1) หรือ natural boundary \(S_1''(x_1) = 0\) ซึ่งทำให้ \(z_1 = z_2\)

3.1 สูตรง่าย ๆ สำหรับคำนวณ

ตั้ง \(z_i = S_i'(x_i)\); \(h_i = x_{i+1} - x_i\):

\[ z_{i+1} = -z_i + 2\left(\frac{y_{i+1} - y_i}{h_i}\right) \]

ด้วย \(z_1\) ที่ต้องกำหนด (Natural: \(z_1 = z_2\))

Polynomial สุดท้าย:

\[ S_i(x) = y_i + z_i(x - x_i) + \left(\frac{z_{i+1} - z_i}{2 h_i}\right)(x - x_i)^2 \]
จากคาบเรียน: \(z_i\) คืออะไร และขั้นตอนที่ต้องจำ
คาบ 12 ต.ค. · คลิป 1 · 49:17–59:54, คลิป 2 · 06:10–06:30
  • อาจารย์ข้าม derivation ส่วนใหญ่ แต่ให้จำว่า \(z_i = S_i'(x_i)\) คือ slope ของชิ้นที่ \(i\) ที่จุดเริ่มของมัน
  • จาก \(S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2\) แทน \(x = x_i\) ได้ \(a_i = y_i\) ส่วน \(S_i'(x) = b_i + 2c_i(x - x_i)\) แทน \(x = x_i\) ได้ \(b_i = z_i\) และใช้เงื่อนไข slope เท่ากันที่รอยต่อได้ \(c_i = \dfrac{z_{i+1} - z_i}{2h_i}\)
  • ขั้นตอนตอนทำโจทย์:
    1. เช็กว่า \(x_i\) ไม่ซ้ำและเรียงจากน้อยไปมาก แล้วหา \(h_i = x_{i+1} - x_i\)
    2. หา \(z_1, \dots, z_n\) จาก recurrence \(z_{i+1} = -z_i + 2\left(\dfrac{y_{i+1} - y_i}{h_i}\right)\) เงื่อนไขที่โจทย์ให้เพิ่มมาใช้ตรงขั้นนี้ เพื่อหา \(z_1\) ตัวแรก
    3. แทน \(z_i\) ลงในสูตร \(S_i\) ทีละช่วง
  • แต่ละ \(S_i\) ใช้ได้เฉพาะใน \([x_i, x_{i+1}]\) ห้ามเอาไปแทนค่า \(x\) นอกช่วง
ตัวอย่าง 3.1 Quadratic Spline ▶

โจทย์: data: \((1,2), (2,3), (3,5)\), \(S'(1) = 2\)

\(h_1 = 1, h_2 = 1\); \(z_1 = 2\) (given)

\(z_2 = -2 + 2(3-2)/1 = 0\); \(z_3 = -0 + 2(5-3)/1 = 4\)

\(S_1(x) = 2 + 2(x-1) + \frac{0-2}{2}(x-1)^2 = 2 + 2(x-1) - (x-1)^2\), \(x \in [1,2]\)

\(S_2(x) = 3 + 0(x-2) + \frac{4-0}{2}(x-2)^2 = 3 + 2(x-2)^2\), \(x \in [2,3]\)

ทำไม \(S'(1) = 2\) แปลว่า \(z_1 = 2\)
คาบ 12 ต.ค. · คลิป 2 · 01:00–04:00

โจทย์เขียน \(S'(1)\) ไม่มี subscript แต่ \(x = 1\) คือ \(x_1\) ซึ่งอยู่ในช่วงแรก \([1,2]\) ตรงนั้น \(S\) ก็คือ \(S_1\) จึงได้ \(S_1'(x_1) = 2\) ตรงกับนิยาม \(z_1 = S_1'(x_1)\) พอดี ต้องจำนิยามของ \(z_i\) ให้ได้ ถึงจะแปลงเงื่อนไขที่โจทย์ให้มาเป็นค่า \(z\) ได้

ตัวอย่างในคาบ 2.2 หา \(a, b, c\) ที่ทำให้ฟังก์ชันเป็น quadratic spline ▶
คาบ 12 ต.ค. · คลิป 2 · 06:44–18:43

โจทย์: ให้ \(p(x)\) เป็น quadratic spline

\[ p(x) = \begin{cases} x^2 + a, & x \in [-5, 0] \\ bx^2, & x \in [0, 1] \\ 1 + cx, & x \in [1, 5] \end{cases} \]

หาค่า \(a, b, c\)

  1. ไม่มีตาราง data แต่อ่านจากช่วงได้ว่ามี 3 ชิ้น จึงมี 4 จุด: \(x_1 = -5,\ x_2 = 0,\ x_3 = 1,\ x_4 = 5\) ตั้งชื่อ \(p_1 = x^2 + a,\ p_2 = bx^2,\ p_3 = 1 + cx\) จุดรอยต่อคือ \(x = 0\) และ \(x = 1\)
  2. ค่าเท่ากันที่ \(x = 0\): \(p_1(0) = p_2(0)\) ได้ \(0 + a = 0\) จึง \(a = 0\)
  3. ค่าเท่ากันที่ \(x = 1\): \(p_2(1) = p_3(1)\) ได้ \(b = 1 + c\)
  4. หาอนุพันธ์: \(p_1'(x) = 2x,\ p_2'(x) = 2bx,\ p_3'(x) = c\)
  5. slope เท่ากันที่ \(x = 0\): \(2(0) = 2b(0)\) ได้ \(0 = 0\) เป็นจริงเสมอ ไม่ได้ข้อมูลใหม่
  6. slope เท่ากันที่ \(x = 1\): \(2b(1) = c\) จึง \(c = 2b\)
  7. แทนลงข้อ 3: \(b = 1 + 2b\) ได้ \(b = -1\) และ \(c = 2b = -2\)

คำตอบ \(a = 0,\ b = -1,\ c = -2\) ลองเช็ก: \(p_2(1) = -1 = p_3(1) = 1 - 2\) และ \(p_2'(1) = -2 = p_3'(1)\)

💡 โจทย์แบบนี้ไม่ต้องใช้สูตร \(z_i\) เลย ใช้แค่นิยามของ quadratic spline สองข้อ (ค่าเท่ากันและ slope เท่ากันที่รอยต่อ) ช่วงสุดท้าย \(1 + cx\) เป็นแค่เส้นตรงก็ยังเป็น quadratic spline ได้ เพราะเงื่อนไขคือ degree \(\le 2\)

อาจารย์พูดถึงข้อสอบ Final เรื่อง spline
คาบ 12 ต.ค. · คลิป 2 · 21:30–23:17, 46:19–47:17
  • ข้อสอบเรื่อง spline อาจให้ทำตามขั้นตอนสูตร หรือถามความเข้าใจแบบตัวอย่าง 2.2 อาจารย์บอกว่า "most of the time I might want to ask you this on the exam" เพื่อดูว่าเข้าใจ concept โดยไม่ต้องคำนวณยาว แต่ก็ต้องแทนสูตรเป็นด้วย
  • สอบนำ cheat sheet เข้าได้ และอาจารย์บอกว่า "I'll type some of the formula for you" จะแจ้งทีหลังว่าให้สูตรไหนบ้าง
  • คะแนนบางส่วน: ถ้าเขียนสิ่งที่เกี่ยวกับโจทย์จริงจะได้คะแนนบ้าง ถ้าเขียนสูตรผิดเรื่อง เช่นโจทย์ให้ใช้ Newton สำหรับ system of nonlinear equations แต่ไปใช้ Newton แบบสมการตัวแปรเดียว จะไม่ได้คะแนนเลย แม้จะลอกสูตรมาครบ

4. Cubic Spline (degree 3) ⭐

Smoothest + accurate — วิธีมาตรฐาน สำหรับ interpolation

\[ S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3 \]

เงื่อนไข (คง \(S, S', S''\) ต่อเนื่อง):

  1. \(S_i(x_i) = y_i, S_i(x_{i+1}) = y_{i+1}\) — ผ่านทุกจุด
  2. \(S_i'(x_{i+1}) = S_{i+1}'(x_{i+1})\) — 1st derivative ต่อเนื่อง
  3. \(S_i''(x_{i+1}) = S_{i+1}''(x_{i+1})\) — 2nd derivative ต่อเนื่อง
จากคาบเรียน: นับเงื่อนไขของ cubic spline และ \(z_i\) ตัวใหม่
คาบ 12 ต.ค. · คลิป 2 · 23:17–33:40
  • unknown: \(a_i, b_i, c_i, d_i\) ชิ้นละ 4 ตัว \(n-1\) ชิ้น รวม \(4n - 4\)
  • สมการ: ผ่านจุดปลาย \(2(n-1)\), \(S'\) เท่ากันที่จุดกลาง \(n-2\), \(S''\) เท่ากันที่จุดกลาง \(n-2\) รวม \(4n - 6\)
  • ขาดไป 2 สมการ โจทย์ cubic spline จึงต้องให้เงื่อนไขเพิ่ม 2 ข้อเสมอ
  • เงื่อนไข \(S''\) เท่ากันแปลว่า concavity ของสองชิ้นที่ติดกันเท่ากันตรงรอยต่อ
  • บางตำราตั้งระบบ \(4n-4\) สมการแล้วแก้ทีเดียว อาจารย์บอกว่าไม่ efficient เพราะระบบใหญ่ วิธีในวิชานี้ดูซับซ้อนกว่าแต่แก้ระบบเล็กกว่ามาก
  • ระวัง: \(z_i\) ของ cubic คือ \(S_i''(x_i)\) (second derivative) ส่วน \(z_i\) ของ quadratic คือ \(S_i'(x_i)\) (first derivative) ใช้ตัวอักษรเดียวกันแต่ความหมายต่างกัน

4.1 ระบบ Tridiagonal สำหรับหา \(z_i = S_i''(x_i)\)

\[ h_{i-1} z_{i-1} + 2(h_{i-1} + h_i) z_i + h_i z_{i+1} = 6\left(\frac{y_{i+1} - y_i}{h_i} - \frac{y_i - y_{i-1}}{h_{i-1}}\right) \]

สำหรับ \(i = 2, \ldots, n-1\) → ได้ \(n - 2\) สมการ, \(n\) unknowns → ต้องการ 2 boundary conditions

จากคาบเรียน: แปลงสูตรเป็น linear system (ตัวอย่าง \(n = 7\))
คาบ 12 ต.ค. · คลิป 2 · 36:42–44:09

สมการเดียวมี \(z\) สามตัว \(z_{i-1}, z_i, z_{i+1}\) แก้ทีละสมการไม่ได้ ต้องเขียนทุกสมการรวมเป็น linear system

ถ้ามี 7 จุดและใช้ natural boundary: \(z_1 = z_7 = 0\) เหลือ unknown 5 ตัวคือ \(z_2, \dots, z_6\) ใช้สูตรที่ \(i = 2, 3, 4, 5, 6\)

  • \(i = 2\): พจน์ \(h_1 z_1\) หายไปเพราะ \(z_1 = 0\) เหลือ \(2(h_1 + h_2)z_2 + h_2 z_3\)
  • \(i = 6\): พจน์ \(h_6 z_7\) หายไปเพราะ \(z_7 = 0\)
  • แถวที่เหลือมีสามพจน์ตามสูตร ได้ matrix แบบ tridiagonal 5×5 ที่มี \(2(h_{i-1} + h_i)\) บนแนวทแยง

ถ้าจุดห่างเท่ากัน \(h_i = \Delta x\) ทุกช่วง: \(2(h_{i-1} + h_i) = 4\Delta x\) จึงเห็นเลข 4 บนแนวทแยง และ 1 ข้างๆ ดึง \(\Delta x\) ออกได้

\[ \Delta x \begin{bmatrix} 4&1&0&0&0\\ 1&4&1&0&0\\ 0&1&4&1&0\\ 0&0&1&4&1\\ 0&0&0&1&4 \end{bmatrix} \begin{bmatrix}z_2\\z_3\\z_4\\z_5\\z_6\end{bmatrix} = \frac{6}{\Delta x}\begin{bmatrix} y_3 - 2y_2 + y_1\\ y_4 - 2y_3 + y_2\\ y_5 - 2y_4 + y_3\\ y_6 - 2y_5 + y_4\\ y_7 - 2y_6 + y_5 \end{bmatrix} \]

อาจารย์บอกว่ากรณีจุดห่างเท่ากันเจอบ่อย เพราะเวลาเลือกจุดเองจากฟังก์ชันมักเลือกให้ห่างเท่ากัน

ขั้นตอนรวม: หา \(h_i\) → ตั้ง linear system หา \(z_1, \dots, z_n\) (ใช้เงื่อนไขเพิ่ม 2 ข้อตรงนี้) → แทน \(z_i\) ใน \(a_i, b_i, c_i, d_i\) → ประกอบ \(S_i\)

4.2 Boundary Conditions

Natural Boundary

\(S''(x_1) = S''(x_n) = 0\)

→ \(z_1 = 0, z_n = 0\)

⭐ นิยมใช้ที่สุด

Clamped Boundary

\(S'(x_1) = \alpha, S'(x_n) = \beta\)

ใช้เมื่อรู้ค่า \(f'(x)\) ที่ปลาย
