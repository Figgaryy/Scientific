บทที่ 12: Eigenvalues (Power Methods)

หา eigenvalues ของ matrix ด้วย iterative methods — Power, Inverse Power, Shifted Power

🎯 เป้าหมายของบท
  • เข้าใจ eigenvalue problem: \(A\mathbf{x} = \lambda\mathbf{x}\)
  • ใช้ Power Method หา dominant (largest) eigenvalue
  • ใช้ Inverse Power Method หา smallest eigenvalue
  • ใช้ Shifted Power / Shifted Inverse Power หา eigenvalue ใกล้/ไกลค่าที่กำหนด

1. Introduction: Eigenvalue Problem

สำหรับ matrix \(A \in \mathbb{C}^{n \times n}\): หา scalar \(\lambda\) และ nonzero vector \(\mathbf{x}\) ที่:

\[ A\mathbf{x} = \lambda\mathbf{x} \]

\(\lambda\) = eigenvalue, \(\mathbf{x}\) = eigenvector, \((\lambda, \mathbf{x})\) = eigenpair

1.1 Characteristic Polynomial

หา \(\lambda\) จาก:

\[ p(\lambda) = \det(A - \lambda I) = 0 \]

⚠️ สำหรับ \(n\) ใหญ่ — คำนวณ determinant ยาก และหา roots ยาก → ใช้ iterative methods

ตัวอย่าง 1.1 หา eigenvalues ของ \(A = \begin{bmatrix}2&1\\0&3\end{bmatrix}\) ▶

\(\det(A - \lambda I) = (2-\lambda)(3-\lambda) - 0 = 0\)

\(\lambda = 2, 3\)

Eigenvector สำหรับ \(\lambda = 2\):

\((A - 2I)\mathbf{v} = \begin{bmatrix}0&1\\0&1\end{bmatrix}\mathbf{v} = 0\) → \(v_2 = 0, v_1 =\) free → \(\mathbf{v} = \begin{bmatrix}1\\0\end{bmatrix}\)

Eigenvector สำหรับ \(\lambda = 3\):

\((A - 3I)\mathbf{v} = \begin{bmatrix}-1&1\\0&0\end{bmatrix}\mathbf{v} = 0\) → \(v_1 = v_2\) → \(\mathbf{v} = \begin{bmatrix}1\\1\end{bmatrix}\)

2. Power Method ⭐

หา dominant eigenvalue (ที่มี \(|\lambda|\) ใหญ่ที่สุด)

2.1 Assumptions

  • \(|\lambda_1| > |\lambda_2| \geq \cdots \geq |\lambda_n|\) (มี unique largest)
  • Eigenvectors \(\mathbf{u}^{(1)}, \ldots, \mathbf{u}^{(n)}\) linearly independent

2.2 Algorithm

\[ \mathbf{x}^{(k+1)} = A\mathbf{x}^{(k)} \] \[ r_k = \frac{\varphi(\mathbf{x}^{(k+1)})}{\varphi(\mathbf{x}^{(k)})} \to \lambda_1 \]

โดย \(\varphi\) เป็น linear functional (เช่น \(\varphi(\mathbf{x}) = x_1\))

⚠️ ต้อง normalize \(\mathbf{x}^{(k)}\) ทุกรอบเพื่อไม่ให้ overflow:

\[ \mathbf{x}^{(k)} \leftarrow \mathbf{x}^{(k)} / \|\mathbf{x}^{(k)}\| \]
ตัวอย่าง 2.1 Power method สำหรับ \(A = \begin{bmatrix}6&5&-5\\2&6&-2\\2&5&-1\end{bmatrix}\) ▶

Eigenvalues จริง: 6, 4, 1 → dominant = 6; eigenvector = [1, 1, 1]ᵀ

\(\mathbf{x}^{(0)} = [-1, 1, 1]^T\), \(\varphi(\mathbf{x}) = x_2\), infinity norm

Iter 1: \(A\mathbf{x}^{(0)} = [6(-1)+5+(-5), 2(-1)+6+(-2), 2(-1)+5+(-1)]^T = [-6, 2, 2]^T\)

\(r_1 = 2/1 = 2\); normalize: /||·||∞ = /6 → \([-1, 0.333, 0.333]^T\)

After many iterations: \(r_k \to 6\), eigenvector \(\to [-1, -1, -1]^T\) (same direction as [1,1,1])

3. Inverse Power Method

หา smallest eigenvalue ของ \(A\)

📌 Theorem

ถ้า \(\lambda\) เป็น eigenvalue ของ \(A\) (nonsingular) → \(1/\lambda\) เป็น eigenvalue ของ \(A^{-1}\)

ใช้ Power method บน \(A^{-1}\) → หา \(1/\lambda_n\) (largest ของ \(A^{-1}\)) → \(\lambda_n\) = smallest ของ \(A\)

3.1 Algorithm (ไม่คำนวณ \(A^{-1}\) ตรง ๆ)

แทน \(\mathbf{x}^{(k+1)} = A^{-1}\mathbf{x}^{(k)}\) ด้วยการแก้:

\[ A\mathbf{x}^{(k+1)} = \mathbf{x}^{(k)} \]

ใช้ LU decomposition ครั้งเดียว → แก้ triangular systems ซ้ำ ๆ

4. Shifted Power / Inverse Power Methods

📌 Theorem (Shifted matrix)

ถ้า \(\lambda\) เป็น eigenvalue ของ \(A\) → \(\lambda - \mu\) เป็น eigenvalue ของ \(A - \mu I\)

Shifted Power Method

หา eigenvalue ไกลสุดจาก \(\mu\)

Apply Power method บน \(A - \mu I\)

\(r_k \to \lambda - \mu\) → \(\lambda = r_k + \mu\)

Shifted Inverse Power

หา eigenvalue ใกล้สุดกับ \(\mu\)

Apply Inverse Power บน \(A - \mu I\)

\(r_k \to 1/(\lambda - \mu)\) → \(\lambda = 1/r_k + \mu\)

ตัวอย่าง 4.1 Shifted power with \(\mu = 7\) ▶

\(A\) มี eigenvalues 6, 4, 1; \(\mu = 7\)

Shifted Power: หา eigenvalue ไกลจาก 7 → \(|1 - 7| = 6\) (ไกลสุด)

\(r_k \to -6\); \(\lambda = -6 + 7 = 1\) ✅

Shifted Inverse: หา eigenvalue ใกล้ 7 → \(|6 - 7| = 1\) (ใกล้สุด)

\(r_k \to 1/(6-7) = -1\); \(\lambda = -1 + 7 = 6\) ✅

💡 \(1/(\lambda-\mu)\) ใหญ่สุดเมื่อ \(\lambda\) ใกล้ \(\mu\) → หา eigenvalue ใกล้ \(\mu\)

💡 Shifted matrix: eigenvalues shift ด้วย \(-\mu\)
