บทที่ 13: Google PageRank Algorithm 🔍

ประยุกต์ Power method กับ Markov chain เพื่อจัดอันดับหน้าเว็บ — Algorithm ที่ Google สร้างชื่อ

🎯 เป้าหมายของบท
  • เข้าใจแนวคิด PageRank — จัดอันดับหน้าเว็บจาก link structure
  • สร้าง Connectivity matrix \(G\) และ Transition matrix \(A\)
  • แก้ \(\mathbf{x} = A\mathbf{x}\) ด้วย power method
  • เข้าใจบทบาทของ damping factor \(p = 0.85\)

1. Introduction

PageRank — algorithm ที่ Larry Page และ Sergey Brin คิดค้นสมัยเรียนป.โทที่ Stanford และกลายเป็นหัวใจของ Google

  • คำนวณจาก link structure ของเว็บทั้งหมด
  • ไม่สนใจเนื้อหาของหน้าเว็บ
  • หลักการ: หน้าเว็บสำคัญ = หน้าเว็บที่หน้าสำคัญ ๆ ลิงก์มา (recursive!)

2. Markov Chain for PageRank

2.1 Notations

  • \(W\) = set of web pages (ประมาณ 3 พันล้านในปี 2002)
  • \(n\) = \(|W|\)
  • \(G\) = \(n \times n\) connectivity matrix: \(g_{ij} = 1\) ถ้ามี link จากหน้า \(j\) ไปหน้า \(i\); 0 ถ้าไม่มี
  • \(c_j = \sum_i g_{ij}\) = out-degree ของหน้า \(j\)
  • \(r_i = \sum_j g_{ij}\) = in-degree ของหน้า \(i\)
  • \(p = 0.85\) = probability ที่ random surfer ตามลิงก์ (1-p ไปที่หน้าสุ่ม)

2.2 Transition Matrix

\[ A = pGD + \mathbf{e}\mathbf{z}^T \]

โดย:

  • \(D\) = diagonal matrix: \(d_{jj} = 1/c_j\) ถ้า \(c_j \neq 0\); = 0 ถ้า \(c_j = 0\)
  • \(\mathbf{e}\) = n-vector ของเลข 1
  • \(\mathbf{z}\) = vector: \(z_j = \delta\) ถ้า \(c_j \neq 0\); = \(1/n\) ถ้า \(c_j = 0\) (dangling nodes)
  • \(\delta = (1-p)/n\)

2.3 PageRank Equation

\[ \mathbf{x} = A\mathbf{x}, \quad \sum_i x_i = 1 \]

คือ \(\mathbf{x}\) เป็น eigenvector ของ \(A\) ที่ eigenvalue = 1

3. Computing PageRank

แก้ singular, homogeneous linear system:

\[ (I - A)\mathbf{x} = 0 \]

3.1 Power Method

เริ่มจาก \(\mathbf{x} = \text{ones}(n, 1)/n\); ทำซ้ำ:

\[ \mathbf{x} \leftarrow A\mathbf{x} \]

จนกระทั่ง \(\mathbf{x}\) converge (\(\|\mathbf{x}^{new} - \mathbf{x}^{old}\|\) น้อย)

3.2 Linear System Approach

แยก \(A = pGD + \delta \mathbf{e}\mathbf{e}^T\) (เมื่อ \(c_j \neq 0\)):

\[ \mathbf{x} = A\mathbf{x} = pGD\mathbf{x} + \delta\mathbf{e}(\mathbf{e}^T\mathbf{x}) \]

เนื่องจาก \(\mathbf{e}^T\mathbf{x} = 1\):

\[ (I - pGD)\mathbf{x} = \delta\mathbf{e} \]

แก้ด้วย Gaussian elimination — รักษา sparsity ของ \(G\)

4. Example: 6-page Web

ตัวอย่าง 4.1 คำนวณ PageRank สำหรับเว็บ 6 หน้า ▶

เว็บ: alpha, beta, gamma, delta, rho, sigma

Connections (indices \(i \leftarrow j\)):

i = [2, 3, 4, 4, 5, 6, 1, 6, 1]

j = [1, 2, 2, 3, 3, 3, 4, 5, 6]

Setup: \(G, D\) sparse matrices; \(p = 0.85, \delta = 0.025\)

Power method converge → PageRank x:

alpha0.267521

💡 Observations
  • alpha อยู่อันดับ 1 แม้มีจำนวน links ไม่ต่างจาก delta/sigma — เพราะหน้าที่ลิงก์มา (beta) มี PageRank สูง
  • beta อันดับ 2 เพราะ beta is linked by alpha (ซึ่งมี PageRank สูง)
  • Random surfer visit alpha ~27% ของเวลา, rho ~6%

5. Properties of A

  • Column sums ของ \(A\) = 1 — คุณสมบัติของ probability transition matrix
  • \(A\) มี eigenvalue 1 เสมอ (dominant)
  • PageRank \(\mathbf{x}\) คือ eigenvector ที่ eigenvalue 1
  • \(x_i \in (0, 1)\) และ \(\sum x_i = 1\)

6. Damping Factor \(p = 0.85\)

ตีความ:

  • 85% ของเวลา: random surfer คลิก link ปัจจุบัน
  • 15% ของเวลา: ไปที่หน้าสุ่มใด ๆ (bored of current page)
💡 ความสำคัญของ \(p < 1\)

ป้องกัน dangling nodes (หน้าที่ไม่มี out-link) ทำให้ Markov chain เป็น ergodic → มี unique steady state
