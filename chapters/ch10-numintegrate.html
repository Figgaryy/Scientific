บทที่ 10: Numerical Integration

ประมาณค่า \(\int_a^b f(x) \, dx\) — Rectangular, Trapezoidal, Simpson's methods

🎯 เป้าหมายของบท
  • ใช้ Rectangle methods (Left, Right, Midpoint) + composite versions
  • ใช้ Trapezoidal method (single + composite)
  • ใช้ Simpson's 1/3 and 3/8 methods
  • วิเคราะห์ error และเลือกจำนวน subintervals \(N\)

1. Introduction

ประมาณค่า definite integral:

\[ I(f) = \int_a^b f(x) \, dx \]

Close Methods

ใช้ endpoints (รวม \(x_1, x_{N+1}\))

ตัวอย่าง: Trapezoidal, Simpson

Open Methods

ไม่ใช้ endpoints

ตัวอย่าง: Midpoint

2. Rectangular Methods

แบ่ง \([a, b]\) เป็น \(N\) sub-intervals width \(h = (b-a)/N\); \(x_i = a + (i-1)h\)

Left Rectangle (Composite)

\[ I(f) \approx h \sum_{i=1}^{N} f(x_i) \]

Right Rectangle

\[ I(f) \approx h \sum_{i=1}^{N} f(x_{i+1}) \]

Midpoint ⭐

\[ I(f) \approx h \sum_{i=1}^{N} f\left(\frac{x_i + x_{i+1}}{2}\right) \]

แม่นกว่า left/right rectangle

ตัวอย่าง 2.1 \(\int_0^2 (x^2 + 1) \, dx\) ▶

\(N = 4, h = 0.5\); points: 0, 0.5, 1, 1.5, 2; midpoints: 0.25, 0.75, 1.25, 1.75

Left: \(0.5(f(0) + f(0.5) + f(1) + f(1.5)) = 0.5(1 + 1.25 + 2 + 3.25) = 3.75\)

Midpoint: \(0.5(f(0.25)+f(0.75)+f(1.25)+f(1.75)) = 0.5(1.0625+1.5625+2.5625+4.0625) = 4.625\)

Exact: \(\int_0^2 (x^2+1)dx = 8/3 + 2 = 4.6667\) → Midpoint ใกล้สุด ✅

3. Trapezoidal Method

ใช้พื้นที่ trapezoid แทน rectangle:

\[ \int_a^b f(x) \, dx \approx \frac{b-a}{2}[f(a) + f(b)] \]

3.1 Composite Trapezoidal

แบ่ง \(N\) sub-intervals width \(h\):

\[ \int_a^b f(x) \, dx \approx \frac{h}{2}[f(a) + f(b)] + h \sum_{i=2}^{N} f(x_i) \]

หรือเขียนเป็น:

\[ \approx \frac{h}{2}[f(x_1) + 2f(x_2) + 2f(x_3) + \cdots + 2f(x_N) + f(x_{N+1})] \]

3.2 Accuracy

\[ \text{Error} = -\frac{1}{12}(b-a)h^2 f''(\xi) = O(h^2) \]
ตัวอย่าง 3.1 จำนวน subintervals สำหรับ \(\int_{-1}^{1} \sin(x) dx\) ▶

Error ≤ \(10^{-4}\); \(|f''(\xi)| = |\sin(\xi)| \leq 1\); \(b - a = 2\)

\(\frac{1}{12}(2)(h^2)(1) \leq 10^{-4}\) → \(h^2 \leq 6 \times 10^{-4}\) → \(h \leq 0.0245\)

\(N \geq 2/0.0245 \approx 81.65\) → \(N = 82\)

4. Simpson's Methods

4.1 Simpson's 1/3 Method ⭐

ใช้ quadratic polynomial — \(N\) ต้องเป็น เลขคู่

\[ \int_a^b f(x) \, dx \approx \frac{h}{3}\left[f(a) + 4\sum_{i=2,4,6,\ldots}^{N} f(x_i) + 2\sum_{i=3,5,7,\ldots}^{N-1} f(x_i) + f(b)\right] \]

Error: \(O(h^4)\) — แม่นกว่า trapezoidal มาก

💡 Simpson's 1/3 Pattern

Coefficients ที่ \(f(x_i)\): 1, 4, 2, 4, 2, ..., 4, 2, 4, 1

สลับ 4 (ที่ odd index เริ่มจาก 2) และ 2 (ที่ even index) → รวม 1 ที่หัว-ท้าย

ตัวอย่าง 4.1 Simpson's 1/3 สำหรับ \(\int_{-1}^{1} \sqrt{x^2+1} dx\), N = 10 ▶

\(h = 0.2\); 11 points: -1, -0.8, -0.6, ..., 0.8, 1

Pattern: 1, 4, 2, 4, 2, 4, 2, 4, 2, 4, 1

\(I \approx \frac{0.2}{3}[1.4142 + 4(1.2806) + 2(1.1662) + 4(1.0770) + 2(1.0198) + 4(1) + 2(1.0198) + 4(1.0770) + 2(1.1662) + 4(1.2806) + 1.4142]\)

\(= 0.0667 \cdot 34.432 = \boxed{2.2956}\) (Exact: 2.2958) ✅

4.2 Simpson's 3/8 Method

ใช้ cubic polynomial — \(N\) ต้องหารด้วย 3 ลงตัว

\[ \int_a^b f(x) \, dx \approx \frac{3h}{8}\left[f(a) + 3\sum_{i \neq 3k} f(x_i) + 2\sum_{i = 3k} f(x_i) + f(b)\right] \]

Pattern: 1, 3, 3, 2, 3, 3, 2, ..., 3, 3, 1

5. สรุป Methods

MethodFormula per subintervalErrorต้องการ
Rectangle (Left/Right)\(h \cdot f(x_i)\)\(O(h)\)-
Midpoint\(h \cdot f((x_i+x_{i+1})/2)\)\(O(h^2)\)-
Trapezoidal\(\frac{h}{2}(f_i + f_{i+1})\)\(O(h^2)\)-
Simpson's 1/3 ⭐\(\frac{h}{3}(f_i + 4f_{i+1} + f_{i+2})\)\(O(h^4)\)\(N\) คู่
Simpson's 3/8\(\frac{3h}{8}(f_i + 3f_{i+1} + 3f_{i+2} + f_{i+3})\)\(O(h^4)\)\(N\) หาร 3 ลงตัว
