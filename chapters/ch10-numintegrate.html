บทที่ 10: Numerical Integration

ประมาณค่า \(\int_a^b f(x) \, dx\) — Rectangular, Trapezoidal, Simpson's methods, Gauss quadrature

🎯 เป้าหมายของบท
  • ใช้ Rectangle methods (Left, Right, Midpoint) + composite versions
  • ใช้ Trapezoidal method (single + composite)
  • ใช้ Simpson's 1/3 and 3/8 methods
  • วิเคราะห์ error และเลือกจำนวน subintervals \(N\)
  • ใช้ Gauss quadrature จากตาราง และเปลี่ยนช่วง \([a, b]\) เป็น \([-1, 1]\)

🧮 บทนี้ใช้ fx-991EX ช่วยได้ ดูปุ่มทีละขั้นที่ หน้าใช้เครื่องคิดเลข

1. Introduction

ประมาณค่า definite integral:

\[ I(f) = \int_a^b f(x) \, dx \]

Close Methods

ใช้ endpoints (รวม \(x_1, x_{N+1}\))

ตัวอย่าง: Trapezoidal, Simpson

Open Methods

ไม่ใช้ endpoints

ตัวอย่าง: Midpoint

2. Rectangular Methods

แบ่ง \([a, b]\) เป็น \(N\) sub-intervals width \(h = (b-a)/N\); \(x_i = a + (i-1)h\)

Left Rectangle (Composite)

\[ I(f) \approx h \sum_{i=1}^{N} f(x_i) \]

Right Rectangle

\[ I(f) \approx h \sum_{i=1}^{N} f(x_{i+1}) \]

Midpoint ⭐

\[ I(f) \approx h \sum_{i=1}^{N} f\left(\frac{x_i + x_{i+1}}{2}\right) \]

แม่นกว่า left/right rectangle

ตัวอย่าง 2.1 \(\int_0^2 (x^2 + 1) \, dx\) ▶

\(N = 4, h = 0.5\); points: 0, 0.5, 1, 1.5, 2; midpoints: 0.25, 0.75, 1.25, 1.75

Left: \(0.5(f(0) + f(0.5) + f(1) + f(1.5)) = 0.5(1 + 1.25 + 2 + 3.25) = 3.75\)

Midpoint: \(0.5(f(0.25)+f(0.75)+f(1.25)+f(1.75)) = 0.5(1.0625+1.5625+2.5625+4.0625) = 4.625\)

Exact: \(\int_0^2 (x^2+1)dx = 8/3 + 2 = 4.6667\) → Midpoint ใกล้สุด ✅

3. Trapezoidal Method

ใช้พื้นที่ trapezoid แทน rectangle:

\[ \int_a^b f(x) \, dx \approx \frac{b-a}{2}[f(a) + f(b)] \]

3.1 Composite Trapezoidal

แบ่ง \(N\) sub-intervals width \(h\):

\[ \int_a^b f(x) \, dx \approx \frac{h}{2}[f(a) + f(b)] + h \sum_{i=2}^{N} f(x_i) \]

หรือเขียนเป็น:

\[ \approx \frac{h}{2}[f(x_1) + 2f(x_2) + 2f(x_3) + \cdots + 2f(x_N) + f(x_{N+1})] \]

3.2 Accuracy

\[ \text{Error} = -\frac{1}{12}(b-a)h^2 f''(\xi) = O(h^2) \]
ตัวอย่าง 3.1 จำนวน subintervals สำหรับ \(\int_{-1}^{1} \sin(x) dx\) ▶

Error ≤ \(10^{-4}\); \(|f''(\xi)| = |\sin(\xi)| \leq 1\); \(b - a = 2\)

\(\frac{1}{12}(2)(h^2)(1) \leq 10^{-4}\) → \(h^2 \leq 6 \times 10^{-4}\) → \(h \leq 0.0245\)

\(N \geq 2/0.0245 \approx 81.65\) → \(N = 82\)

4. Simpson's Methods

4.1 Simpson's 1/3 Method ⭐

ใช้ quadratic polynomial — \(N\) ต้องเป็น เลขคู่

\[ \int_a^b f(x) \, dx \approx \frac{h}{3}\left[f(a) + 4\sum_{i=2,4,6,\ldots}^{N} f(x_i) + 2\sum_{i=3,5,7,\ldots}^{N-1} f(x_i) + f(b)\right] \]

Error: \(O(h^4)\) — แม่นกว่า trapezoidal มาก

💡 Simpson's 1/3 Pattern

Coefficients ที่ \(f(x_i)\): 1, 4, 2, 4, 2, ..., 4, 2, 4, 1

สลับ 4 (ที่ odd index เริ่มจาก 2) และ 2 (ที่ even index) → รวม 1 ที่หัว-ท้าย

ตัวอย่าง 4.1 Simpson's 1/3 สำหรับ \(\int_{-1}^{1} \sqrt{x^2+1} dx\), N = 10 ▶

\(h = 0.2\); 11 points: -1, -0.8, -0.6, ..., 0.8, 1

Pattern: 1, 4, 2, 4, 2, 4, 2, 4, 2, 4, 1

\(I \approx \frac{0.2}{3}[1.4142 + 4(1.2806) + 2(1.1662) + 4(1.0770) + 2(1.0198) + 4(1) + 2(1.0198) + 4(1.0770) + 2(1.1662) + 4(1.2806) + 1.4142]\)

\(= 0.0667 \cdot 34.432 = \boxed{2.2956}\) (Exact: 2.2956) ✅

4.2 Simpson's 3/8 Method

ใช้ cubic polynomial — \(N\) ต้องหารด้วย 3 ลงตัว

\[ \int_a^b f(x) \, dx \approx \frac{3h}{8}\left[f(x_1) + 3\sum_{\substack{i=2 \\ i \ne 4,7,\ldots}}^{N} f(x_i) + 2\sum_{i=4,7,10,\ldots}^{N-2} f(x_i) + f(x_{N+1})\right] \]

Pattern: 1, 3, 3, 2, 3, 3, 2, ..., 3, 3, 1

ตัวอย่างในคาบ 4.2 ใช้ Simpson's 1/3 กับ 3/8 ในข้อเดียว ▶

  • \(w_1 = \tfrac{h}{3},\ w_2 = \tfrac{4h}{3},\ w_3 = \tfrac{2h}{3},\ w_4 = \tfrac{4h}{3}\) มาจาก 1/3
  • \(w_5 = \tfrac{h}{3} + \tfrac{3h}{8}\) เพราะ \(x_5\) อยู่ในทั้งสองสูตร ถ้าสองช่วงใช้ \(h\) ต่างกัน ต้องใส่ \(h\) ของแต่ละช่วงแยกกัน
  • \(w_6 = w_7 = \tfrac{9h}{8},\ w_8 = \tfrac{3h}{8}\) มาจาก 3/8
  • แทน \(h = 0.1\) ได้ \(w_5 \approx 0.0708\) และผลรวมของ \(w_i\) ทั้งหมดเท่ากับ \(0.7 = b - a\) ใช้เช็กได้ว่าน้ำหนักไม่ผิด (ลองกับ \(f(x) = 1\) จะเห็นว่าต้องเป็นอย่างนั้น)

ใน Rectangular, Trapezoidal และ Simpson เราเป็นคนเลือกจุด \(x_i\) เอง ส่วน \(w_i\) ถูกกำหนดโดยวิธีที่ใช้ แบบฝึกหัดข้อ 1 ในโน้ตถามแบบเดียวกันกับ composite trapezoidal: \(w_1 = w_{N+1} = \tfrac{h}{2}\) และ \(w_i = h\) สำหรับ \(i = 2, \dots, N\)

5. Gauss Quadrature

เขียนการประมาณในรูปเดียวกับ Simpson แต่คราวนี้ทั้ง weight \(A_i\) และจุด \(x_i\) ถูกกำหนดมาให้ เราเลือกได้แค่จำนวนพจน์ \(n\)

\[ \int_{-1}^{1} f(x)\,dx \approx \sum_{i=1}^{n} A_i f(x_i) = A_1 f(x_1) + A_2 f(x_2) + \cdots + A_n f(x_n) \]

หา \(A_i, x_i\) (มี \(2n\) unknowns) จากเงื่อนไขว่าสูตรต้องให้ค่า exact สำหรับ \(f(x) = 1, x, x^2, \dots, x^{2n-1}\)

📌 Gauss quadrature \(n\) พจน์ exact สำหรับ polynomial degree \(0\) ถึง \(2n-1\)

\(n = 1\) exact ถึง degree 1, \(n = 2\) ถึง degree 3, \(n = 3\) ถึง degree 5

จากคาบเรียน: Gauss ต่างจาก Simpson ตรงไหน
คาบ 2 พ.ย. · คลิป 1 · 25:43–29:30, 55:00–56:20
  • ใน Simpson และ trapezoidal "the point here is always something that you can specify by yourself, the weight is kind of fixed" คือเราเลือก \(x_i\) เอง แล้ววิธีที่ใช้บอก \(w_i\)
  • Gauss quadrature ให้ทั้ง \(A_i\) และ \(x_i\) มาเลย สิ่งเดียวที่เลือกได้คือ \(n\) จำนวนพจน์ อาจารย์เขียนบนกระดานว่า \(n\) "we can choose" ส่วน \(A_i, x_i\) "given"
  • ไม่ต้องรู้เทคนิค integration ใดๆ แค่แทน \(A_i\) และ \(x_i\) ให้ถูก
  • สูตรทั้งหมดสร้างบนช่วง \([-1, 1]\) ก่อน ช่วงอื่นค่อยแปลงทีหลัง (ข้อ 5.2)
ตัวอย่างในคาบ 5.1 หา \(A_i, x_i\) เองสำหรับ \(n = 1\) และ \(n = 2\) ▶
คาบ 2 พ.ย. · คลิป 1 · 29:30–48:51

โจทย์: หา weight และจุดของ Gauss quadrature บน \([-1, 1]\)

\(n = 1\): สูตรคือ \(\int_{-1}^{1} f\,dx \approx A_1 f(x_1)\) มี 2 unknowns จึงใช้ 2 เงื่อนไข (\(2n - 1 = 1\) คือ \(f = 1\) และ \(f = x\))

  1. \(f(x) = 1\): exact \(= \int_{-1}^{1} 1\,dx = 2\) ส่วน approx \(= A_1 \cdot 1 = A_1\) ให้เท่ากัน ได้ \(A_1 = 2\)
  2. \(f(x) = x\): exact \(= \left[\tfrac{x^2}{2}\right]_{-1}^{1} = 0\) ส่วน approx \(= A_1 x_1\) ได้ \(A_1 x_1 = 0\) และเพราะ \(A_1 = 2 \ne 0\) จึงต้องมี \(x_1 = 0\)
  3. ได้สูตร \(\int_{-1}^{1} f\,dx \approx 2f(0)\) ในโน้ตบอกว่าสูตรนี้คือ midpoint method นั่นเอง

ตัวอย่างบนกระดาน: \(\int_{-1}^{1} \cos x\,dx \approx 2\cos(0) = 2\) และ \(\int_{-1}^{1} \sqrt{x^5 + 4}\,dx \approx 2\sqrt{0^5 + 4} = 4\)

\(n = 2\): สูตรคือ \(A_1 f(x_1) + A_2 f(x_2)\) มี 4 unknowns จึงต้องใช้ 4 เงื่อนไข \(f = 1, x, x^2, x^3\)

\[ \begin{aligned} A_1 + A_2 &= 2 \\ A_1 x_1 + A_2 x_2 &= 0 \\ A_1 x_1^2 + A_2 x_2^2 &= \tfrac{2}{3} \\ A_1 x_1^3 + A_2 x_2^3 &= 0 \end{aligned} \]
  1. ระบบนี้เป็น nonlinear (มีกำลังสองกำลังสามคูณกับ \(A_i\)) แก้ไม่ง่าย คำตอบคือ \(A_1 = A_2 = 1,\ x_1 = -\tfrac{1}{\sqrt{3}},\ x_2 = \tfrac{1}{\sqrt{3}}\)
  2. ได้สูตร \(\int_{-1}^{1} f\,dx \approx f\!\left(-\tfrac{1}{\sqrt{3}}\right) + f\!\left(\tfrac{1}{\sqrt{3}}\right)\)

💡 ข้อสอบไม่ให้ derive เอง เพราะ \(n\) ยิ่งมากระบบ nonlinear ยิ่งใหญ่ อาจารย์บอกว่า "we are not going to do this, … we are going to use table" ค่าในตารางใช้ได้กับทุก \(f\) เพราะช่วง \([-1, 1]\) ตายตัว

ใช้ \(2n - 1\) รู้ได้ทันทีว่า error เป็นศูนย์ไหม
คาบ 2 พ.ย. · คลิป 1 · 49:50–57:00
  • \(n = 3\) exact ถึง degree \(2(3) - 1 = 5\) ดังนั้น \(\int_{-1}^{1} (3x^5 + 2x + 1)\,dx\) ด้วย 3 พจน์ได้ค่าเท่ากับ exact คือ 2 โดยไม่ต้องคำนวณ

  • ตารางในโน้ตมีคอลัมน์ "Degree of Precision" ที่เขียน 2, 4, 6, … ซึ่งเท่ากับ \(2n\) ไม่ตรงกับกฎที่อาจารย์สอนและที่อยู่ในกรอบของโน้ตเอง ให้ใช้ \(2n - 1\) (เช่น \(n = 2\) ใช้กับ \(x^4\) จะไม่ exact: \(f(\pm\tfrac{1}{\sqrt{3}})\) รวมได้ \(\tfrac{2}{9}\) แต่ exact คือ \(\tfrac{2}{5}\))

โจทย์ (a) (Example 4.1): ใช้ Gauss 1 พจน์และ 2 พจน์ แล้วหา relative error

  1. \(n = 1\): \(2f(0) = 2(0 + 0 + 1) = 2\)
  2. \(n = 2\): \(f(-\tfrac{1}{\sqrt{3}}) + f(\tfrac{1}{\sqrt{3}})\) พจน์ \(4x^3\) สองตัวเครื่องหมายตรงข้ามจึงตัดกันหมด เหลือ \(\tfrac{1}{3} + \tfrac{1}{3} + 1 + 1 = \tfrac{8}{3}\)
  3. Exact: \(\left[x^4 + \tfrac{x^3}{3} + x\right]_{-1}^{1} = \tfrac{8}{3}\)
  4. Relative error \(= \dfrac{|\text{exact} - \text{approx}|}{|\text{exact}|}\): \(n = 1\) ได้ \(\dfrac{8/3 - 2}{8/3} = 0.25\) ส่วน \(n = 2\) ได้ 0

อาจารย์ถามว่าที่ \(n = 2\) ได้ค่าตรงเป๊ะเป็น "by accident" หรือเปล่า คำตอบคือไม่ใช่ \(f\) เป็น degree 3 และ \(n = 2\) exact ถึง degree 3 พอดี ถ้าข้อสอบถาม error ของกรณีนี้ ตอบได้ว่าเป็นศูนย์โดยไม่ต้องคำนวณ

โจทย์ (b) (Example 4.2): ใช้ 1 พจน์และ 3 พจน์ \(f(x) = \sqrt{x^2+1}\) ไม่ใช่ polynomial จึงไม่คาดว่า error จะเป็นศูนย์

  1. \(n = 1\): \(2\sqrt{0^2 + 1} = 2\)
  2. \(n = 3\): \(f(\pm\sqrt{3/5}) = \sqrt{\tfrac{3}{5} + 1} = \sqrt{1.6} = 1.2649\) (รากที่สองยกกำลังสองกลับเป็น \(3/5\) คิดง่าย)
    \[ \tfrac{5}{9}(1.2649) + \tfrac{8}{9}(1) + \tfrac{5}{9}(1.2649) = 1.4055 + 0.8889 = 2.2943 \]
  3. ข้อนี้อาจารย์ไม่ให้หา exact ถ้าอยากเทียบ exact คือ \(\sqrt{2} + \ln(1+\sqrt{2}) \approx 2.2956\) Gauss 3 พจน์ใช้ค่า \(f\) แค่ 3 จุดแต่ได้ใกล้เคียงกับ Simpson \(N = 10\) ในตัวอย่าง 4.1 ที่ใช้ 11 จุด

5.2 เปลี่ยนช่วงจาก \([a, b]\) เป็น \([-1, 1]\)

ใช้ \(x = u(t) = \frac{b-a}{2}(t+1) + a\) แล้ว \(dx = \frac{b-a}{2}\,dt\) ได้

\[ \int_a^b f(x)\,dx \approx \frac{b-a}{2} \sum_{i=1}^{n} A_i\, f\!\left(\frac{b-a}{2}(t_i + 1) + a\right) \]

\(A_i, t_i\) มาจากตารางในข้อ 5.1 ส่วน \(a, b\) มาจากโจทย์

จากคาบเรียน: \(u(t)\) มาจากไหน
คาบ 2 พ.ย. · คลิป 2 · 13:13–21:04

อาจารย์ทำเหมือน substitution ใน Calculus

  1. ตั้ง \(x = u(t)\) เป็นเส้นตรงที่พา \(t = c\) ไปที่ \(x = a\) และ \(t = d\) ไปที่ \(x = b\): \(u(t) = \dfrac{b-a}{d-c}(t - c) + a\)
  2. เช็ก: \(u(c) = 0 + a = a\) และ \(u(d) = (b - a) + a = b\) ใช้ได้
  3. \(dx = u'(t)\,dt\) และ \(u'(t) = \dfrac{b-a}{d-c}\) เป็นค่าคงที่ ดึงออกมาหน้า integral ได้
    \[ \int_a^b f(x)\,dx = \frac{b-a}{d-c} \int_c^d f\!\left(\frac{b-a}{d-c}(t - c) + a\right) dt \]
  4. ตารางของเราทำไว้สำหรับ \([-1, 1]\) จึงแทน \(c = -1,\ d = 1\) ได้ \(d - c = 2\) และ \(t - c = t + 1\) ออกมาเป็นสูตรในกรอบด้านบน
ตัวอย่างในคาบ 5.3 \(\int_1^5 \sqrt{x^2+1}\,dx\) ด้วย Gauss 3 พจน์ ▶
คาบ 2 พ.ย. · คลิป 2 · 21:04–30:31

โจทย์ (Example 4.3): \(a = 1,\ b = 5,\ n = 3,\ f(x) = \sqrt{x^2 + 1}\)

  1. เขียนโครงก่อน: \(\int_1^5 f\,dx \approx \dfrac{5-1}{2}\big[A_1 f(u_1) + A_2 f(u_2) + A_3 f(u_3)\big]\) โดย \(A_1 = A_3 = \tfrac{5}{9},\ A_2 = \tfrac{8}{9}\) จากตาราง
  2. หา \(u_i = \tfrac{5-1}{2}(t_i + 1) + 1\) แยกทีละตัว อาจารย์ทำแบบนี้เพราะดูง่ายกว่าแทนทีเดียว
    • \(u_1 = 2\left(-\sqrt{3/5} + 1\right) + 1 = 1.4508\)
    • \(u_2 = 2(0 + 1) + 1 = 3\)
    • \(u_3 = 2\left(\sqrt{3/5} + 1\right) + 1 = 4.5492\)
  3. แทนใน \(f\): \(f(u_1) = \sqrt{1.4508^2 + 1} = 1.7621,\ f(u_2) = \sqrt{10} = 3.1623,\ f(u_3) = \sqrt{4.5492^2 + 1} = 4.6578\)
  4. \(\int_1^5 f\,dx \approx 2\left[\tfrac{5}{9}(1.7621) + \tfrac{8}{9}(3.1623) + \tfrac{5}{9}(4.6578)\right] = 2(6.3775) = 12.7550\) (exact \(\approx 12.7560\))

💡 ตอนเขียนบนกระดาน อาจารย์ลืม "\(+\,a\)" ท้ายสูตร \(u_i\) นักศึกษาทักแล้วจึงเติม \(+1\) เช็กง่ายๆ ว่า \(u_i\) ทุกตัวต้องอยู่ใน \([a, b]\) ถ้าไม่อยู่แปลว่าแปลงช่วงผิด อาจารย์ยังบอกด้วยว่าถ้าแทนค่าถูกขั้นตอน ตัวเลขสุดท้ายคลาดไปบ้างก็ยังได้คะแนน

ตัวอย่างในคาบ 5.4 \(\int \cos x\,dx\) บน \([-1, 1]\) และ \([0, \pi/2]\) ▶
คาบ 2 พ.ย. · คลิป 2 · 30:31–45:26

โจทย์ (Example 4.4): (a) \(\int_{-1}^{1} \cos x\,dx\) (b) \(\int_0^{\pi/2} \cos x\,dx\) ใช้ 1 พจน์และ 2 พจน์ และหา relative error ของ (b)

(a) ช่วง \([-1, 1]\) ใช้ตารางตรงๆ

  1. \(n = 1\): \(2\cos(0) = 2\)
  2. \(n = 2\): \(\cos(-\tfrac{1}{\sqrt{3}}) + \cos(\tfrac{1}{\sqrt{3}}) = 2(0.8379) = 1.6758\) (radian)
  3. Exact \(= 2\sin 1 = 1.6829\)

(b) \(a = 0,\ b = \pi/2\) ต้องแปลงช่วง \(\frac{b-a}{2} = \frac{\pi}{4}\) Exact \(= [\sin x]_0^{\pi/2} = 1\)

  1. \(n = 1\): \(\frac{\pi}{4} \cdot 2 \cdot \cos\!\left(\frac{\pi}{4}(0 + 1) + 0\right) = \frac{\pi}{2}\cos\frac{\pi}{4} = \frac{\pi}{2} \cdot \frac{1}{\sqrt{2}} = 1.1107\)
  2. \(n = 2\): \(u_1 = \frac{\pi}{4}\left(-\tfrac{1}{\sqrt{3}} + 1\right) = 0.3319,\ u_2 = \frac{\pi}{4}\left(\tfrac{1}{\sqrt{3}} + 1\right) = 1.2388\)
    \[ \int_0^{\pi/2} \cos x\,dx \approx \frac{\pi}{4}\big[\cos(0.3319) + \cos(1.2388)\big] = \frac{\pi}{4}(0.9454 + 0.3259) = 0.9985 \]
  3. Relative error: \(n = 1\) ได้ \(\frac{|1 - 1.1107|}{1} = 0.1107\) ส่วน \(n = 2\) ได้ \(\frac{|1 - 0.9985|}{1} = 0.0015\)

💡 ในคาบอาจารย์เขียน \(u_1 = 1.3319\) ก่อน นักศึกษาทักว่าค่าที่ถูกคือ \(0.3319\) อาจารย์ใช้เหตุผลว่า \(\frac{\pi}{4}(1 - 0.577)\) ต้องน้อยกว่า 1 ข้อนี้เช็กได้ด้วยว่า \(u_1 < u_2\) และทั้งคู่อยู่ใน \([0, \pi/2]\) ถ้าลืมเปลี่ยนเครื่องคิดเลขเป็น radian จะได้ค่าผิดทั้งข้อ

practice final ข้อ 7: Gauss 2 พจน์กับ \(x^5\)
คาบ 2 พ.ย. · คลิป 2 · 05:58–09:06, 45:26–46:25

practice final ให้ \(\int_1^3 x^5\,dx\) ด้วย Gauss 2 พจน์ ข้อนี้ \(f\) เป็น polynomial แต่ degree 5 เกิน \(2(2) - 1 = 3\) จึงไม่ exact ห้ามตอบว่า error เป็นศูนย์

  • \(\frac{b-a}{2} = 1\) และ \(u_i = (t_i + 1) + 1 = 2 \mp \tfrac{1}{\sqrt{3}} = 1.4226,\ 2.5774\)
  • \(\int_1^3 x^5\,dx \approx 1.4226^5 + 2.5774^5 = 5.8276 + 113.7280 = 119.5556\)
  • exact \(= \frac{3^6 - 1}{6} = 121.3333\) relative error \(\approx 0.0147\) ถ้าใช้ 3 พจน์ (exact ถึง degree 5) จะได้ 121.3333 พอดี
