บทที่ 4: Linear Systems — Iterative Methods

Vector/Matrix Norms, Jacobi, Gauss-Seidel, SOR — วิธีการทำซ้ำสำหรับระบบสมการเชิงเส้นขนาดใหญ่

🎯 เป้าหมายของบท
  • เข้าใจ Vector norms (1, 2, ∞) และ Matrix norms
  • ใช้ Jacobi และ Gauss-Seidel iteration
  • ใช้ SOR (Successive Over-Relaxation) และเลือก \(\omega\) ที่เหมาะสม
  • เข้าใจเงื่อนไข convergence (Diagonally dominant)
  • เปรียบเทียบวิธี direct vs iterative

1. Introduction: Iterative Methods

Iterative = ทำซ้ำ ใช้ค่าประมาณปัจจุบัน \(\mathbf{x}^{current}\) เพื่อสร้างค่าประมาณใหม่ \(\mathbf{x}^{new}\) ที่ใกล้ค่าจริงมากขึ้น

  • เริ่มจาก initial guess \(\mathbf{x}^{(0)}\), ใช้สูตร update ได้ \(\mathbf{x}^{(1)}, \mathbf{x}^{(2)}, \ldots\)
  • คาดหวังว่า \(\mathbf{x}^{(k)} \to \mathbf{x}\) เมื่อ \(k \to \infty\)
  • ตรวจสอบความใกล้เคียงได้จาก residual \(\|A\mathbf{x}^{(k)} - \mathbf{b}\|\) หรือ \(\|\mathbf{x}^{(k)} - \mathbf{x}^{(k-1)}\|\)

เพื่อวัดขนาด vector และ matrix เราต้องใช้ norms

2. Vector และ Matrix Norms

2.1 Vector Norms

สำหรับ \(\mathbf{x} = [x_1, x_2, \ldots, x_n]^T \in \mathbb{R}^n\):

Euclidean norm (2-norm หรือ \(\ell_2\)-norm):

\[ \|\mathbf{x}\|_2 = \sqrt{x_1^2 + x_2^2 + \cdots + x_n^2} \]

1-norm:

\[ \|\mathbf{x}\|_1 = |x_1| + |x_2| + \cdots + |x_n| \]

Infinity norm (\(\ell_\infty\)-norm):

\[ \|\mathbf{x}\|_\infty = \max_{i=1,\ldots,n} |x_i| \]

p-norm (ทั่วไป):

\[ \|\mathbf{x}\|_p = \left(\sum_{i=1}^n |x_i|^p\right)^{1/p} \]
ตัวอย่าง 2.1 Vector Norms ของ \(\mathbf{x} = [1, -2, -3, 0, -1]^T\) ▶

2-norm: \(\|\mathbf{x}\|_2 = \sqrt{1^2 + (-2)^2 + (-3)^2 + 0^2 + 1^2} = \sqrt{15} = 3.8730\)

1-norm: \(\|\mathbf{x}\|_1 = 1 + 2 + 3 + 0 + 1 = 7\)

∞-norm: \(\|\mathbf{x}\|_\infty = \max\{1, 2, 3, 0, 1\} = 3\)

2.2 Matrix Norms

สำหรับ \(A = [a_{ij}] \in \mathbb{R}^{n \times n}\):

Infinity Norm (max row sum):

\[ \|A\|_\infty = \max_{1 \leq i \leq n} \sum_{j=1}^n |a_{ij}| \]

1-Norm (max column sum):

\[ \|A\|_1 = \max_{1 \leq j \leq n} \sum_{i=1}^n |a_{ij}| \]

Frobenius Norm:

\[ \|A\|_F = \sqrt{\sum_{i=1}^n \sum_{j=1}^n a_{ij}^2} \]

Condition Number:

\[ \text{Cond}(A) = \|A\| \cdot \|A^{-1}\| \]
ตัวอย่าง 2.2 Matrix Norms และ Condition Number ▶

โจทย์: \(A = \begin{bmatrix}1&-1&0\\2&-1&0\\1&1&1\end{bmatrix}\); \(A^{-1} = \begin{bmatrix}-1&1&0\\-2&1&0\\3&-2&1\end{bmatrix}\)

\(\|A\|_\infty\): max ของ row sum = \(\max(2, 3, 3) = 3\)

\(\|A\|_1\): max ของ column sum = \(\max(4, 3, 1) = 4\)

\(\|A\|_F\): \(\sqrt{1+1+0+4+1+0+1+1+1} = \sqrt{10} = 3.1623\)

Cond(\(A\)) (1-norm): \(\|A\|_1 \cdot \|A^{-1}\|_1 = 4 \times 6 = 24\)

3. General Iterative Form

รูปแบบทั่วไป:

\[ \mathbf{x}^{(k)} = T\mathbf{x}^{(k-1)} + \mathbf{c}, \quad k = 1, 2, 3, \ldots \]

โดย \(T \in \mathbb{R}^{n \times n}\) และ \(\mathbf{c} \in \mathbb{R}^n\) ต้องเลือกให้ \(\mathbf{x} = T\mathbf{x} + \mathbf{c}\) มี solution เดียวกับ \(A\mathbf{x} = \mathbf{b}\)

💡 Theorem 2.1 — Convergence

ถ้า \(\|T\| < 1\) (โดย subordinate matrix norm):

  • \(\{\mathbf{x}^{(k)}\}\) converge ไป solution สำหรับทุก \(\mathbf{x}^{(0)}\)
  • Error bound: \(\|\mathbf{x} - \mathbf{x}^{(k)}\| \leq \|T\|^k \|\mathbf{x} - \mathbf{x}^{(0)}\|\)
  • \(\|\mathbf{x} - \mathbf{x}^{(k)}\| \leq \frac{\|T\|^k}{1-\|T\|}\|\mathbf{x}^{(1)} - \mathbf{x}^{(0)}\|\)

เขียน \(A = D + L + U\) โดย:

  • \(D\) = diagonal เท่านั้น
  • \(L\) = strictly lower (ใต้ diagonal)
  • \(U\) = strictly upper (บน diagonal)

4. Jacobi Method

จาก row \(i\) แต่ละแถว: \(\sum_j a_{ij}x_j = b_i\) → แก้หา \(x_i\):

\[ x_i = \frac{1}{a_{ii}}\left(b_i - \sum_{\substack{j=1 \\ j \neq i}}^{n} a_{ij}x_j\right) \]

สูตร Jacobi Update:

\[ x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{\substack{j=1 \\ j \neq i}}^{n} a_{ij}x_j^{(k)}\right) \]

ในรูป matrix: \(T = -D^{-1}(L + U), \quad \mathbf{c} = D^{-1}\mathbf{b}\)

4.1 Convergence: Diagonally Dominant

\(A\) เป็น diagonally dominant เมื่อ:

\[ |a_{ii}| > \sum_{\substack{j=1 \\ j \neq i}}^{n} |a_{ij}|, \quad \forall i \]

ถ้า \(A\) diagonally dominant → Jacobi (และ Gauss-Seidel) converge เสมอ

ตัวอย่าง 4.1 Jacobi สำหรับระบบ 3×3 ▶

โจทย์: \(5x_1 + x_2 + 2x_3 = 7; 2x_1 + 7x_2 + x_3 = 3; x_1 + 3x_2 + 8x_3 = 9\)

\(\mathbf{x}^{(0)} = [0, 0, 0]^T\), ทำ 3 iterations

สูตร Update:

\[ x_1^{(k+1)} = \frac{1}{5}(7 - x_2^{(k)} - 2x_3^{(k)}) \] \[ x_2^{(k+1)} = \frac{1}{7}(3 - 2x_1^{(k)} - x_3^{(k)}) \] \[ x_3^{(k+1)} = \frac{1}{8}(9 - x_1^{(k)} - 3x_2^{(k)}) \]

Iteration 1: \(\mathbf{x}^{(0)} = [0, 0, 0]\)

  • \(x_1^{(1)} = 7/5 = 1.4000\)
  • \(x_2^{(1)} = 3/7 = 0.4286\)
  • \(x_3^{(1)} = 9/8 = 1.1250\)

Iteration 2: ใช้ \(\mathbf{x}^{(1)} = [1.4, 0.4286, 1.125]\)

  • \(x_1^{(2)} = (7 - 0.4286 - 2.25)/5 = 0.8643\)
  • \(x_2^{(2)} = (3 - 2.8 - 1.125)/7 = -0.1321\)
  • \(x_3^{(2)} = (9 - 1.4 - 1.2858)/8 = 0.7893\)

Iteration 3: ใช้ \(\mathbf{x}^{(2)}\)

  • \(x_1^{(3)} = 1.1107, x_2^{(3)} = 0.0689, x_3^{(3)} = 1.0665\)

Errors (iteration 3):

\(\|\mathbf{x}^{(3)} - \mathbf{x}^{(2)}\|_2 = 0.4219\); \(\|\cdot\|_\infty = 0.2772\)

💡 ค่าจริงคือ \([1, 0, 1]^T\) — Jacobi จะ converge (matrix เป็น diagonally dominant) แต่ต้อง ~17 iterations เพื่อให้ error < \(10^{-4}\)

5. Gauss-Seidel Method

เหมือน Jacobi แต่ ใช้ค่าใหม่ที่คำนวณได้แล้วในรอบเดียวกันทันที:

\[ x_i^{(k+1)} = \frac{1}{a_{ii}}\left(b_i - \sum_{j=1}^{i-1} a_{ij}x_j^{(k+1)} - \sum_{j=i+1}^{n} a_{ij}x_j^{(k)}\right) \]

ในรูป matrix: \(T = -(D+L)^{-1}U, \quad \mathbf{c} = (D+L)^{-1}\mathbf{b}\)

💡 Jacobi vs Gauss-Seidel
  • Jacobi: ใช้ทั้งหมดค่าจาก iteration ก่อน (\(k\))
  • Gauss-Seidel: ใช้ค่าใหม่ (\(k+1\)) ที่คำนวณแล้วในรอบนี้ทันที
  • Gauss-Seidel converge เร็วกว่า Jacobi (โดยทั่วไป)
  • เงื่อนไข convergence เดียวกัน (diagonally dominant)
ตัวอย่าง 5.1 Gauss-Seidel สำหรับระบบเดิม ▶

โจทย์: เดียวกับตัวอย่าง 4.1, \(\mathbf{x}^{(0)} = [0,0,0]\), 3 iterations

สูตร Update:

\[ x_1^{(k+1)} = \frac{1}{5}(7 - x_2^{(k)} - 2x_3^{(k)}) \] \[ x_2^{(k+1)} = \frac{1}{7}(3 - 2x_1^{(k+1)} - x_3^{(k)}) \] \[ x_3^{(k+1)} = \frac{1}{8}(9 - x_1^{(k+1)} - 3x_2^{(k+1)}) \]

สังเกตว่า \(x_2^{(k+1)}\) ใช้ \(x_1^{(k+1)}\) (ค่าใหม่) แล้ว!

Iteration 1:

  • \(x_1^{(1)} = 7/5 = 1.4\)
  • \(x_2^{(1)} = (3 - 2 \cdot 1.4 - 0)/7 = 0.0286\)
  • \(x_3^{(1)} = (9 - 1.4 - 3 \cdot 0.0286)/8 = 0.9393\)

Iteration 2:

  • \(x_1^{(2)} = (7 - 0.0286 - 2 \cdot 0.9393)/5 = 1.0186\)
  • \(x_2^{(2)} = (3 - 2 \cdot 1.0186 - 0.9393)/7 = 0.0034\)
  • \(x_3^{(2)} = (9 - 1.0186 - 3 \cdot 0.0034)/8 = 0.9964\)

Iteration 3:

  • \(x_1^{(3)} = 1.0008, x_2^{(3)} = 0.0003, x_3^{(3)} = 0.9998\)

Errors (iteration 3):

\(\|\mathbf{x}^{(3)} - \mathbf{x}^{(2)}\|_2 = 0.0184\); \(\|\cdot\|_\infty = 0.0178\)

🎉 Gauss-Seidel เร็วกว่า Jacobi มาก! — iteration 3 ของ GS ได้ error 0.018 เทียบกับ Jacobi 0.42 (ลดลง ~20 เท่า)

6. SOR (Successive Over-Relaxation)

เป็น generalization ของ Gauss-Seidel โดยใช้ relaxation factor \(\omega\):

\[ x_i^{(k)} = (1-\omega)x_i^{(k-1)} + \frac{\omega}{a_{ii}}\left(b_i - \sum_{j=1}^{i-1} a_{ij}x_j^{(k)} - \sum_{j=i+1}^{n} a_{ij}x_j^{(k-1)}\right) \]

ประเภทของ SOR

  • \(\omega = 1\): = Gauss-Seidel
  • \(0 < \omega < 1\): Under-relaxation
  • \(1 < \omega < 2\): Over-relaxation

Theorems สำคัญ

Kahan: ถ้า SOR converge → \(0 < \omega < 2\)

Ostrowski-Reich: ถ้า \(A\) positive definite และ \(0 < \omega < 2\) → SOR converge

Matrix Form:

\[ T_\omega = (D + \omega L)^{-1}[(1-\omega)D - \omega U], \quad \mathbf{c}_\omega = \omega(D + \omega L)^{-1}\mathbf{b} \]
ตัวอย่าง 6.1 SOR สำหรับระบบ 3×3 ด้วย \(\omega = 1.25\) ▶

โจทย์: \(4x_1 + 3x_2 = 24; 3x_1 + 4x_2 - x_3 = 30; -x_2 + 4x_3 = -24\)

\(\mathbf{x}^{(0)} = [1, 1, 1]^T\), ค่าจริง \([3, 4, -5]^T\)

สูตร Update (ω = 1.25):

\[ x_1^{(k)} = -\frac{1}{4}x_1^{(k-1)} + \frac{5}{16}(24 - 3x_2^{(k-1)}) \] \[ x_2^{(k)} = -\frac{1}{4}x_2^{(k-1)} + \frac{5}{16}(30 - 3x_1^{(k)} + x_3^{(k-1)}) \] \[ x_3^{(k)} = -\frac{1}{4}x_3^{(k-1)} + \frac{5}{16}(-24 + x_2^{(k)}) \]

Iteration 1:

  • \(x_1^{(1)} = -1/4 + (5/16)(21) = 6.3125\)
  • \(x_2^{(1)} = -1/4 + (5/16)(30 - 18.9375 + 1) = 3.5195\)
  • \(x_3^{(1)} = -1/4 + (5/16)(-24 + 3.5195) = -6.6501\)

Iteration 2: \(x_1^{(2)} = 2.6223, x_2^{(2)} = 3.9585, x_3^{(2)} = -4.6004\)

Iteration 3: \(x_1^{(3)} = 3.1333, x_2^{(3)} = 4.0103, x_3^{(3)} = -5.0967\)

Errors (iter 3): \(\|\mathbf{x}^{(3)} - \mathbf{x}^{(2)}\|_\infty = 0.5110\)

🚀 SOR ที่ \(\omega = 1.25\) converge เร็ว — Iteration 3 ใกล้ค่าจริง [3, 4, -5] แล้ว

ตัวอย่าง 6.2 เปรียบเทียบ Jacobi/GS/SOR สำหรับ Banded Matrix ▶

โจทย์: \(A = \text{tridiag}(-1, 2, -1)\) ขนาด 5×5, \(\mathbf{b} = [9, 0, 0, 0, 15]^T\)

ค่าจริง \(\mathbf{x} = [10, 11, 12, 13, 14]^T\)

Stopping criterion: \(\|\mathbf{x}^{(k)} - \mathbf{x}^{(k-1)}\|_\infty \leq 0.01\)

7. การสร้าง Matrix \(T\) และ Vector \(\mathbf{c}\)

ตัวอย่าง 7.1 \(T, \mathbf{c}\) สำหรับระบบ 3×3 ▶

โจทย์: \(4x_1 + 3x_2 = 1; 3x_1 + 4x_2 - x_3 = 0; -x_2 + 4x_3 = 1\)

\(A = \begin{bmatrix}4&3&0\\3&4&-1\\0&-1&4\end{bmatrix}, \mathbf{b} = [1, 0, 1]^T\)

\(D = \text{diag}(4, 4, 4)\), \(L\) มีเฉพาะ \(a_{21}=3, a_{32}=-1\), \(U\) มีเฉพาะ \(a_{12}=3, a_{23}=-1\)

Jacobi: \(T = -D^{-1}(L+U), \mathbf{c} = D^{-1}\mathbf{b}\)

\[ T = \begin{bmatrix} 0 & -3/4 & 0 \\ -3/4 & 0 & 1/4 \\ 0 & 1/4 & 0 \end{bmatrix}, \quad \mathbf{c} = \begin{bmatrix} 1/4 \\ 0 \\ 1/4 \end{bmatrix} \]

Gauss-Seidel: \(T = -(D+L)^{-1}U, \mathbf{c} = (D+L)^{-1}\mathbf{b}\)

\[ (D+L)^{-1} = \begin{bmatrix} 1/4 & 0 & 0 \\ -3/16 & 1/4 & 0 \\ -3/64 & 1/16 & 1/4 \end{bmatrix} \] \[ T = \begin{bmatrix} 0 & -3/4 & 0 \\ 0 & 9/16 & 1/4 \\ 0 & 9/64 & 1/16 \end{bmatrix}, \quad \mathbf{c} = \begin{bmatrix} 1/4 \\ -3/16 \\ 13/64 \end{bmatrix} \]
