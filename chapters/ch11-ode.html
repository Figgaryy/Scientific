บทที่ 11: Numerical Methods for ODEs

แก้สมการอนุพันธ์สามัญ (ODE) อันดับ 1 ด้วย Taylor, Euler, Midpoint, Modified Euler, Runge-Kutta

🎯 เป้าหมายของบท
  • เข้าใจ initial value problem (IVP): \(y' = f(x, y), y(x_1) = y_1\)
  • ใช้ Euler's Explicit/Implicit methods
  • ใช้ Midpoint และ Modified Euler (Heun's method)
  • เข้าใจ Taylor series method order \(n\)
  • เข้าใจ Runge-Kutta methods (RK2, RK4)

1. Introduction

Initial Value Problem (IVP):

\[ \frac{dy}{dx} = f(x, y), \quad y(x_1) = y_1 \]

ตัวอย่าง: \(y' = -2y, y(0) = 10\); หา \(y(x)\) สำหรับ \(x > 0\)

1.1 ประเภทของวิธี

  • Explicit: \(y_{i+1} = F(y_i)\) (ใช้ค่าปัจจุบัน)
  • Implicit: \(y_{i+1} = F(y_i, y_{i+1})\) (ต้องแก้สมการ)
  • Single-step: ใช้ \(y_i\) เพื่อหา \(y_{i+1}\)
  • Multi-step: ใช้ \(y_{i-m+1}, \ldots, y_i\)

2. สรุป Methods และ Error Order

MethodLocal Truncation ErrorGlobal Truncation Error
Euler's Explicit\(O(h^2)\)\(O(h)\)
Euler's Implicit\(O(h^2)\)\(O(h)\)
Midpoint\(O(h^3)\)\(O(h^2)\)
Modified Euler (Heun)\(O(h^3)\)\(O(h^2)\)
Runge-Kutta order \(n\)\(O(h^{n+1})\)\(O(h^n)\)

3. Taylor Series Method

\[ y_{i+1} = y_i + f(x_i, y_i) h + \frac{f'(x_i, y_i)}{2!}h^2 + \cdots + \frac{f^{(n-1)}(x_i, y_i)}{n!}h^n \]

คำนวณ \(f', f'', \ldots\) จาก:

\[ f'(x, y) = \frac{\partial f}{\partial x} + \frac{\partial f}{\partial y} \cdot \frac{dy}{dx} = f_x + f_y \cdot f \]

4. Euler's Explicit Method

Special case ของ Taylor series order 1:

\[ y_{i+1} = y_i + f(x_i, y_i) \cdot h \]
ตัวอย่าง 4.1 Euler's Explicit สำหรับ \(y' = x + y + 1, y(0) = 0\) ▶

\(h = 1\); \(f(x, y) = x + y + 1\)

Iteration:

\(y_2 = y_1 + f(0, 0)(1) = 0 + 1 = 1\)

\(y_3 = y_2 + f(1, 1)(1) = 1 + 3 = 4\)

Exact: \(y(x) = 2e^x - x - 2\); \(y(1) = 2e - 3 = 2.4366\); \(y(2) = 2e^2 - 4 = 10.778\)

Error ที่ \(x = 1\): \(|y(1) - y_2| = 1.4366\); Error ที่ \(x = 2\): \(|10.778 - 4| = 6.778\)

5. Euler's Implicit Method

\[ y_{i+1} = y_i + f(x_{i+1}, y_{i+1}) \cdot h \]

⚠️ Implicit — ต้องแก้ \(y_{i+1}\) จากสมการ

ตัวอย่าง 5.1 Implicit Euler สำหรับ \(y' = x + y + 1, y(0) = 0\) ▶

\(y_{i+1} = y_i + (x_{i+1} + y_{i+1} + 1)h\)

แก้: \(y_{i+1}(1 - h) = y_i + (x_{i+1} + 1)h\) → \(y_{i+1} = \frac{y_i + h(x_{i+1} + 1)}{1 - h}\)

\(h = 0.5\): \(y_2 = (0 + 0.5(1.5))/(0.5) = 1.5\); \(y_3 = (1.5 + 0.5(2))/0.5 = 5\)

6. Midpoint Method

\[ y_{i+1} = y_i + f(x_m, y_m) \cdot h \] \[ \text{โดย } x_m = x_i + \frac{h}{2}, \quad y_m = y_i + \frac{h}{2} f(x_i, y_i) \]

Error: \(O(h^2)\) — ดีกว่า Euler

7. Modified Euler's Method (Heun's)

Predictor-Corrector:

  1. Predictor: \(y_{i+1}^0 = y_i + h \cdot f(x_i, y_i)\) (Explicit Euler)
  2. Corrector: \(y_{i+1} = y_i + h \cdot \frac{f(x_i, y_i) + f(x_{i+1}, y_{i+1}^0)}{2}\)

Error: \(O(h^2)\)

ตัวอย่าง 7.1 Modified Euler สำหรับ \(y' = x + y + 1, y(0) = 0\) ▶

\(h = 1\); \(f(x, y) = x + y + 1\)

Step 1 (x = 0 → 1):

Predictor: \(y_2^0 = 0 + 1 \cdot f(0, 0) = 1\)

Corrector: \(y_2 = 0 + 1 \cdot \frac{f(0, 0) + f(1, 1)}{2} = \frac{1 + 3}{2} = 2\)

Error: \(|2.4366 - 2| = 0.4366\) ← ดีกว่า Euler 1.4366 มาก!

8. Runge-Kutta Methods

8.1 RK2 (Second-order Runge-Kutta)

\[ y_{i+1} = y_i + (c_1 K_1 + c_2 K_2) h \] \[ K_1 = f(x_i, y_i), \quad K_2 = f(x_i + a_2 h, y_i + b_{21} K_1 h) \]

Constraints: \(c_1 + c_2 = 1, c_2 a_2 = 1/2, c_2 b_{21} = 1/2\)

ค่าที่นิยม:

  • \(c_1 = c_2 = 1/2, a_2 = b_{21} = 1\) → Heun's (= Modified Euler)
  • \(c_1 = 0, c_2 = 1, a_2 = b_{21} = 1/2\) → Midpoint

8.2 RK4 (Fourth-order) ⭐

วิธีมาตรฐานทองคำ — error \(O(h^4)\):

\[ y_{i+1} = y_i + \frac{h}{6}(K_1 + 2K_2 + 2K_3 + K_4) \]
\[ K_1 = f(x_i, y_i) \] \[ K_2 = f(x_i + h/2, y_i + K_1 h/2) \] \[ K_3 = f(x_i + h/2, y_i + K_2 h/2) \] \[ K_4 = f(x_i + h, y_i + K_3 h) \]
