บทที่ 2: Root Finding (1D)

วิธีการเชิงตัวเลขสำหรับหารากของสมการ \(f(x) = 0\): Bisection, False Position, Newton-Raphson, Secant, Fixed-Point

🎯 เป้าหมายของบท
  • เข้าใจ Bracketing methods (Bisection, False Position) — ต้องใช้ interval, converge เสมอ
  • เข้าใจ Open methods (Newton-Raphson, Secant, Fixed-Point) — ต้องใช้ initial guess, converge เร็วกว่าแต่อาจไม่ converge
  • คำนวณ Absolute error, Relative error, Residual ในแต่ละ iteration
  • รู้เงื่อนไข convergence และเงื่อนไขหยุด (stopping criteria)

1. Introduction

พิจารณาฟังก์ชัน \(f(x)\) และสมการ \(f(x) = 0\)

  • Solution (root): ค่า \(x\) ที่ทำให้ \(f(x) = 0\)
  • คือจุดบนแกน x ที่กราฟ \(f(x)\) ตัดหรือแตะแกน x
  • บนโดเมน \(D\) อาจมี: ไม่มี solution, มีเพียง solution เดียว, หรือมีหลาย solutions

1.1 การประมาณ Error ในเชิงตัวเลข

ให้ \(x_\tau\) คือ true solution และ \(\tilde{x}\) คือค่าที่ประมาณจากวิธีการเชิงตัวเลข:

1. Error ในค่า Solution

True Error: \(\hat{E}_\tau = |x_\tau - \tilde{x}|\)

True Relative Error: \(E_r = |(x_\tau - \tilde{x})/x_\tau|\)

Estimate Relative Error: \(\tilde{E}_r = |(\tilde{x}_j - \tilde{x}_{j-1})/\tilde{x}_j|\)

2. Error ในค่าฟังก์ชัน (Residual)

\(f(x_\tau) = 0\) จึงได้:

\(E_f = |f(x_\tau) - f(\tilde{x})| = |f(\tilde{x})|\)

เรียกว่า residual

🛑 Stopping Criteria

ในกระบวนการ iteration หยุดเมื่อเงื่อนไขข้อใดข้อหนึ่งเป็นจริง:

  1. \(|\tilde{x}_j - \tilde{x}_{j-1}| < TOL\) หรือ \(\left|\frac{\tilde{x}_j - \tilde{x}_{j-1}}{\tilde{x}_j}\right| < TOL\)
  2. \(|f(\tilde{x}_j)| < TOL\)
  3. \(j > N_{max}\)

1.2 แนวทางการหาราก

🎯 Bracketing methods

  • ต้องใช้ initial interval [a, b] ที่มี root
  • ลดขนาด interval ซ้ำ ๆ
  • Converge เสมอ
  • ตัวอย่าง: Bisection, False Position

🚀 Open methods

  • ต้องใช้ "good" initial guess
  • อาจไม่ converge (ขึ้นกับ initial)
  • ถ้า converge → เร็วกว่า bracketing
  • ตัวอย่าง: Newton-Raphson, Secant, Fixed-Point

2. Bisection Method (วิธีแบ่งครึ่งช่วง)

ใช้ closed interval \([a, b]\) ที่มี root โดยเริ่มจากกลาง interval:

\[ \tilde{x}_1 = \frac{a+b}{2} \]

เงื่อนไขเลือก interval: เครื่องหมายของ \(f(a)\) และ \(f(b)\) ต้องต่างกัน:

\[ f(a) \cdot f(b) < 0 \Rightarrow x_\tau \in [a, b] \]

2.1 ขั้นตอนการทำงาน

Step 1: หา \([a, b]\) ที่ \(f(a) \cdot f(b) < 0\)
Step 2: คำนวณ \(\tilde{x} = (a+b)/2\)
Step 3: ลด interval:
  • ถ้า \(f(a) \cdot f(\tilde{x}) < 0\) → root อยู่ใน \([a, \tilde{x}]\) → เปลี่ยน \(b \leftarrow \tilde{x}\)
  • ถ้าไม่ใช่ → root อยู่ใน \([\tilde{x}, b]\) → เปลี่ยน \(a \leftarrow \tilde{x}\)
กลับไป Step 2

2.2 จำนวน Iteration ที่ต้องใช้

เนื่องจาก bisection ลดขนาด interval ครึ่งหนึ่งทุก iteration:

\[ |x_\tau - \tilde{x}_n| < \frac{b-a}{2^n} \]

เพื่อให้ \(|x_\tau - \tilde{x}_n| < TOL\):

\[ n > \log_2\left(\frac{b-a}{TOL}\right) \]
ตัวอย่าง 2.1 คำนวณจำนวน iteration ▶

โจทย์: ให้ \(a = 0.1, b = 1.0\) ต้องการ error \(\leq 0.5 \times 10^{-8}\) — ต้องใช้กี่ iteration?

วิธีทำ: \(n > \log_2\left(\frac{1.0 - 0.1}{0.5 \times 10^{-8}}\right) = \log_2(1.8 \times 10^{8})\)

\(= \log_2(1.8) + \log_2(10^8) = 0.848 + 8 \times 3.322 = 27.42\)

ตอบ: ต้องใช้ \(n = 28\) iterations

ตัวอย่าง 2.2 Bisection สำหรับ \(x^4 - 2x^3 - 10 = 0\) บน [1, 3] ▶

โจทย์: ประมาณรากด้วย Bisection 3 iterations เริ่มจาก interval [1, 3]

\(f(x) = x^4 - 2x^3 - 10\); \(f(1) = -11 < 0\); \(f(3) = 17 > 0\) → มีรากใน [1, 3]

Iteration 1: \(a_1 = 1, b_1 = 3\); \(x_1 = 2\)

  • \(f(1) = -11\), \(f(2) = -10\), \(f(3) = 17\)
  • Sign ของ \(f(2)\) และ \(f(3)\) ต่างกัน → interval ใหม่: [2, 3]
  • Residual: \(|f(2)| = 10\)

Iteration 2: \(a_2 = 2, b_2 = 3\); \(x_2 = 2.5\)

  • \(f(2.5) = -2.1875\); interval ใหม่: [2.5, 3]
  • Absolute error: \(|x_2 - x_1| = 0.5\)
  • Relative error: \(0.5/2.5 = 0.2\)
  • Residual: 2.1875

Iteration 3: \(a_3 = 2.5, b_3 = 3\); \(x_3 = 2.75\)

  • Absolute error: \(|2.75 - 2.5| = 0.25\)
  • Relative error: \(0.25/2.75 = 0.0909\)
  • Residual: \(|f(2.75)| = 5.5977\)

💡 ค่าจริงคือ \(x_\tau \approx 2.5814\) — Bisection จะ converge ต่อเนื่องแต่ค่อนข้างช้า

ตัวอย่าง 2.3 หาจุดตัด \(y = 3x\) กับ \(y = e^x\) บน [0, 1] ▶

โจทย์: หาจุดตัดของกราฟ \(y = 3x\) และ \(y = e^x\) บน [0, 1] ด้วย Bisection 3 iterations

ตั้งฟังก์ชัน: \(f(x) = e^x - 3x\); \(f(0) = 1 > 0\); \(f(1) = -0.2817 < 0\) → มีรากใน [0, 1]

Iteration 1: \(x_1 = 0.5\); \(f(0.5) = 0.1487 > 0\) → interval ใหม่: [0.5, 1]

Iteration 2: \(x_2 = 0.75\); \(f(0.75) = -0.1330 < 0\) → interval ใหม่: [0.5, 0.75]

Iteration 3: \(x_3 = 0.625\); Absolute error \(= |0.625 - 0.75| = 0.125\)

3. False Position Method (Regula Falsi)

คล้าย Bisection แต่แทนที่จะใช้ midpoint จะใช้จุดที่ secant line จาก \((a, f(a))\) ถึง \((b, f(b))\) ตัดแกน x

สมการเส้นตรงผ่าน \((a, f(a))\) และ \((b, f(b))\):

\[ y = f(a) + \left(\frac{f(b) - f(a)}{b - a}\right)(x - a) \]

เมื่อ \(y = 0\):

\[ \tilde{x} = \frac{af(b) - bf(a)}{f(b) - f(a)} \]
ตัวอย่าง 3.1 False Position สำหรับ \(x^4 - 2x^3 - 10 = 0\) ▶

โจทย์: ใช้ False Position 3 iterations เริ่มจาก [1, 3]

\(f(1) = -11, f(3) = 17\)

Iteration 1: \(x_1 = \frac{1 \cdot 17 - 3 \cdot (-11)}{17 - (-11)} = \frac{17 + 33}{28} = \frac{50}{28} = 1.7857\)

\(f(1.7857) = -11.2 < 0\) → interval ใหม่: [1.7857, 3]

Iteration 2: \(x_2 = \frac{1.7857 \cdot 17 - 3 \cdot (-11.2)}{17 - (-11.2)} = 2.2685\)

\(f(2.2685) = -6.8654 < 0\) → interval ใหม่: [2.2685, 3]

Iteration 3: \(x_3 = \frac{2.2685 \cdot 17 - 3 \cdot (-6.8654)}{17 - (-6.8654)} = 2.4789\)

  • Absolute error: \(|2.4789 - 2.2685| = 0.2104\)
  • Relative error: \(0.2104/2.4789 = 0.0849\)
  • Residual: \(|f(2.4789)| = 2.7041\)

💡 False Position converge เร็วกว่า Bisection มาก (bisection ที่ iter 3 ให้ 2.75, error 0.25; false position ให้ 2.4789, error 0.21 — ใกล้ค่าจริง 2.5814 กว่า)

4. Newton-Raphson Method

เป็น open method ที่ใช้ tangent line ของ \(f(x)\) เพื่อหาค่าประมาณต่อไป

เส้นสัมผัสที่ \((x_0, f(x_0))\) มี slope \(f'(x_0)\):

\[ y - f(x_0) = f'(x_0)(x - x_0) \]

ตัดแกน x (\(y = 0\)):

\[ x_1 = x_0 - \frac{f(x_0)}{f'(x_0)} \]

สูตรทั่วไป:

\[ x_j = x_{j-1} - \frac{f(x_{j-1})}{f'(x_{j-1})}, \quad j = 1, 2, 3, \ldots \]

4.1 เงื่อนไข Convergence

Newton-Raphson converge เมื่อ:

  1. \(f(x), f'(x), f''(x)\) ต่อเนื่องรอบราก
  2. \(f'(x_\tau) \neq 0\) (ราก simple)
  3. Initial value \(x_0\) ใกล้พอกับราก \(x_\tau\)
⚠️ ข้อควรระวัง

Newton-Raphson ไม่การันตี converge — ถ้า \(f'(x_j)\) ใกล้ 0 อาจ diverge; ถ้า initial ไม่ดี อาจ oscillate หรือไปหารากอื่น

ตัวอย่าง 4.1 Newton สำหรับ \(x^4 - 2x^3 - 10 = 0, x_0 = 1\) ▶

โจทย์: ใช้ Newton 3 iterations, \(x_0 = 1\)

\(f(x) = x^4 - 2x^3 - 10\); \(f'(x) = 4x^3 - 6x^2\)

Iteration 1: \(f(1) = -11\), \(f'(1) = -2\)

\(x_1 = 1 - \frac{-11}{-2} = 1 - 5.5 = -4.5\)

Iteration 2: \(f(-4.5) = 582.31\), \(f'(-4.5) = -486\)

\(x_2 = -4.5 - \frac{582.31}{-486} = -4.5 + 1.198 = -3.3018\)

Iteration 3: \(x_3 = -3.3018 - \frac{f(-3.3018)}{f'(-3.3018)} = -2.4382\)

  • Absolute error: \(|{-2.4382} - ({-3.3018})| = 0.8637\)
  • Relative error: 0.3542
  • Residual: \(|f(-2.4382)| = 54.328\)

⚠️ สังเกตว่า Newton ตอนแรก "หนี" ไปทางลบมาก เพราะ \(f'(1)\) เล็ก แต่ในที่สุดจะ converge ไป root ที่ \(-1.4287\) (ไม่ใช่ +2.5814!) — แสดงว่า Newton อาจไปหารากอื่นถ้า initial ไม่ดี

ตัวอย่าง 4.2 Newton สำหรับ \(e^x - 3x = 0, x_0 = 1\) ▶

โจทย์: ใช้ Newton หา root จนกระทั่ง residual < \(10^{-4}\)

\(f(x) = e^x - 3x\); \(f'(x) = e^x - 3\)

Iter 1: \(x_1 = 1 - \frac{e^1 - 3}{e^1 - 3} = 1 - 1 = 0\); \(|f(0)| = 1\)

Iter 2: \(x_2 = 0 - \frac{1}{e^0 - 3} = 0 - \frac{1}{-2} = 0.5\); \(|f(0.5)| = 0.1487\)

Iter 3: \(x_3 = 0.5 - \frac{0.1487}{e^{0.5} - 3} = 0.6101\); \(|f(0.6101)| = 0.01036\)

Iter 4: \(x_4 = 0.6190\); \(|f(0.6190)| = 7.37 \times 10^{-5} < 10^{-4}\) ✅

ตอบ: 4 iterations, root ≈ 0.6190

5. Secant Method

คล้าย Newton แต่แทน \(f'(x_j)\) ด้วย secant slope จากสองจุดล่าสุด:

\[ m_j = \frac{f(x_j) - f(x_{j-1})}{x_j - x_{j-1}} \]

สูตร update:

\[ x_{j+1} = x_j - \frac{f(x_j)}{m_j} = x_j - \frac{f(x_j)(x_j - x_{j-1})}{f(x_j) - f(x_{j-1})} \]
💡 ข้อเปรียบเทียบ Secant vs Newton
  • Newton: ใช้ \(f'(x)\) — ต้องรู้อนุพันธ์ (บางครั้งคำนวณยาก)
  • Secant: ใช้ 2 initial values, ไม่ต้องรู้ derivative → practical กว่า
  • Secant converge ช้ากว่า Newton เล็กน้อย (order ≈ 1.618 vs 2)
  • ต่างจาก Bisection: initial 2 จุดไม่จำเป็นต้องมี root ตรงกลาง
ตัวอย่าง 5.1 Secant สำหรับ \(x^4 - 2x^3 - 10 = 0, x_0 = 1, x_1 = 2\) ▶

โจทย์: ใช้ Secant 3 iterations, \(x_0 = 1, x_1 = 2\)

\(f(1) = -11, f(2) = -10\)

Iteration 1:

\(m_1 = \frac{f(2) - f(1)}{2 - 1} = \frac{-10 - (-11)}{1} = 1\)

\(x_2 = 2 - \frac{f(2)}{m_1} = 2 - \frac{-10}{1} = 12\)

Iteration 2: \(f(12) = 17270\), \(m_2 = \frac{17270 - (-10)}{12 - 2} = 1728\)

\(x_3 = 12 - \frac{17270}{1728} = 2.0058\)

Iteration 3: \(x_4 = 2.0058 - \frac{f(2.0058)(2.0058 - 12)}{f(2.0058) - f(12)} = 2.0115\)

  • Absolute error: \(|2.0115 - 2.0058| = 5.7567 \times 10^{-3}\)
  • Relative error: \(2.8618 \times 10^{-3}\)
  • Residual: 9.9060

6. Fixed-Point Iteration

เขียนสมการใหม่ในรูป \(x = g(x)\) — root ของ \(f(x) = 0\) คือ fixed point ของ \(g(x)\)

สูตร update:

\[ x_{i+1} = g(x_i) \]

6.1 การเลือก \(g(x)\)

สำหรับ \(f(x) = 0\) เขียนเป็น \(x = g(x)\) ได้หลายแบบ เช่นสำหรับ \(f(x) = x^2 - x - 2\):

  • \(g(x) = x^2 - 2\) (แบบ 1)
  • \(g(x) = 1 + \frac{2}{x}\) (แบบ 2)
  • \(g(x) = f(x) + x\) (แบบง่ายเสมอ)

ควรเลือก \(g(x)\) ที่ทำให้ iterations converge

6.2 ทฤษฎีบทเงื่อนไข Convergence

Theorem 6.1 (Fixed-point Convergence)

ให้ \(g \in C[a, b]\) และ \(g(x) \in [a, b]\) สำหรับทุก \(x \in [a, b]\) มี \(g'(x)\) บน \((a, b)\) และมีค่าคงที่ \(k \in (0, 1)\) ที่:

\[ |g'(x)| \leq k \quad \forall x \in (a, b) \]

สำหรับทุก initial \(x_0 \in [a, b]\):

  1. ลำดับ \(\{x_n\}\) converge ไปที่ fixed point เดียวใน \([a, b]\)
  2. Error bound: \(|x_n - x^*| \leq \frac{k^n}{1-k}|x_1 - x_0|\)

📌 หมายเหตุ: \(k\) ยิ่งเล็ก → convergence ยิ่งเร็ว

ตัวอย่าง 6.1 เปรียบเทียบ Convergent vs Divergent \(g(x)\) ▶

โจทย์: ประมาณราก \(f(x) = \cos(x) - xe^x = 0\) โดยใช้:

  • \(g_1(x) = \cos(x)/e^x\)
  • \(g_2(x) = \cos(x) - xe^x + x\)

วิธีวิเคราะห์: รากอยู่ในช่วง \([0.3, 0.6]\) (ประมาณ 0.518)

ตรวจ \(g_1'(x)\): \(g_1'(x) = -e^{-x}\cos(x) - e^{-x}\sin(x)\)

  • \(g_1'(0.3) = -0.9267\), \(|g_1'(0.3)| = 0.9267 < 1\)
  • \(g_1'(0.6) = -0.7628\), \(|g_1'(0.6)| = 0.7628 < 1\)
  • ดังนั้น \(|g_1'(x)| < 1\) บนช่วง → Convergent ✅

ตรวจ \(g_2'(x)\): \(g_2'(x) = -\sin(x) - xe^x - e^x + 1\)

  • \(g_2'(0.3) = -1.0503\), \(|g_2'(0.3)| = 1.0503 > 1\)
  • \(g_2'(0.6) = -2.4800\), \(|g_2'(0.6)| = 2.4800 > 1\)
  • ดังนั้น \(|g_2'(x)| \geq 1\) → Divergent ❌
ตัวอย่าง 6.2 Fixed-Point สำหรับ \(e^x - 3x = 0, x_0 = 0\) ▶

โจทย์: ประมาณราก โดยใช้ 3 iterations ของ Fixed-Point ด้วย 2 iteration functions:

  1. \(g_1(x) = \frac{1}{3}e^x\)
  2. \(g_2(x) = e^x - 2x\)

วิธีทำสำหรับ \(g_1(x) = \frac{1}{3}e^x\):

Iter 1: \(x_1 = g_1(0) = 1/3 = 0.3333\); Residual \(|f(0.3333)| = 0.3956\)

Iter 2: \(x_2 = g_1(1/3) = \frac{1}{3}e^{1/3} = 0.4652\); Residual = 0.1967

Iter 3: \(x_3 = g_1(0.4652) = 0.5308\); Residual = 0.1079

วิธีทำสำหรับ \(g_2(x) = e^x - 2x\):

Iter 1: \(x_1 = g_2(0) = 1 - 0 = 1\); Residual \(|e^1 - 3| = 0.2817\)

Iter 2: \(x_2 = g_2(1) = e^1 - 2 = 0.7183\); Residual = 0.1039

Iter 3: \(x_3 = g_2(0.7183) = 0.6143\); Residual = 5.4 × 10⁻³

💡 \(g_2\) converge เร็วกว่า \(g_1\) — สังเกตว่า \(g_2\) ให้ residual น้อยกว่า \(g_1\) ในทุก iteration

7. สรุปเปรียบเทียบวิธีทั้ง 5

💡 \(x_1 = \frac{1 \cdot f(3) - 3 \cdot f(1)}{f(3) - f(1)} = \frac{1 \cdot 5 - 3 \cdot (-3)}{5 - (-3)} = \frac{5 + 9}{8} = \frac{14}{8} = 1.75\); ตัวเลขไม่ตรง (root คือ 2 พอดี) — ลอง \(f(x) = x^2 - 6.25\): x1 = 2.5 (root)
8 Newton method อาจ diverge เมื่อ?

9 Residual สำหรับ approximation \(\tilde{x}\) คือ?
💡 Residual คือ \(|f(\tilde{x})|\) เพราะ \(f(x_\tau) = 0\)
